# 로컬 리뷰 실행기

## 사용자 에이전트 자동 연결

권장 진입점은 저장소 루트에서 `python3 .scripts/bin/onboard_research.py`다. 본인의 설치된 Codex·Claude와 로그인 상태를 감지하고 연결 설정을 저장한 뒤 HTML 서버와 브라우저를 연다. 에이전트 선택을 고정하려면 `--agent codex` 또는 `--agent claude`를 붙인다. `--check`는 읽기 전용이다. 계정 인증 정보는 공식 CLI가 관리하며 연결 파일에는 이름만 남긴다.

CLI 실행 옵션 검사를 통과하지 못하거나 PDF 읽기 도구가 없으면 이유를 표시한다. HTML은 `/api/status`에서 연결된 에이전트를 확인하고, 리뷰 요청은 그 에이전트로 실행한다. 실행 중인 작업은 시작할 때 선택한 에이전트를 유지한다.



`100-views/paper-library.html`은 정적 파일만으로 에이전트를 실행하지 않는다. 로컬 리뷰를 시작하려면 저장소 루트에서 다음 실행기를 띄우고 그 실행기가 안내하는 로컬 주소로 라이브러리를 연다.

```bash
python3 .scripts/bin/paper_review_bridge.py serve
```

기본 주소는 `http://127.0.0.1:8765/100-views/paper-library.html`이다. `리뷰 시작`은 클릭한 논문 slug 하나만 보내고, 실행기는 한 번에 한 작업만 큐에 넣는다. 본인의 로그인된 Codex 또는 준비된 Claude와 `pdftotext`가 필요하다. PDF는 원문 페이지 범위를 10쪽 이내로 추출해 읽으며, 스캔 PDF나 읽기 실패는 완료 처리하지 않는다.

리뷰 에이전트는 저장소의 임시 작업 복사본에서 실행된다. 선택한 PDF만 복사하고 나머지 원문 PDF는 제외한다. `.mcp.json`, `.env*`, `.claude/`, `.codex/`, `.secrets/`, `credentials.json`도 복사하지 않으며, 복사본 밖을 가리키는 심볼릭 링크는 제거한다. 작업 전후 파일 상태를 비교하며 리뷰 Markdown, 선택 논문 JSON, 논문 인덱스, 카탈로그, Graphify 출력, 개념 후보 초안만 게시 후보로 받는다. JSON 스키마·5축 필드·실제 읽은 범위·Graphify 성공을 복사 전 확인하고, 실행 중 원본 파일이 바뀌었으면 해당 출력 게시를 거부한다. 실패 상태와 오류 요약은 `04-Projects/review-queue/queue.json`에 남긴다.

브리지는 `127.0.0.1`에만 바인딩하고 브라우저 요청의 `Origin`·`Host`를 같은 로컬 출처로 제한한다. 임의 shell 명령이나 파일 경로를 요청으로 받지 않는다. 이 실행기는 리뷰가 필요한 논문 한 편에 대한 전용 어댑터이며, 사고실험 문헌 조사 실행은 별도 Orca TODO 어댑터를 사용한다.

## 실행 오류 수정 (2026-10-06)

`codex exec`에는 대화형 CLI의 `--ask-for-approval` 옵션을 전달하지 않는다. 비대화형 승인은 `-c approval_policy="never"`로 지정하고, `.git`을 제외한 임시 작업 폴더는 `--skip-git-repo-check`로 실행한다. 실제 설치된 CLI가 실행 인자를 파싱하는 회귀 테스트를 유지한다. 서버가 이미 실행 중이면 코드 수정 후 작업이 끝난 시점에 재시작해야 한다.

페이지를 새로 열어도 실행 중인 작업을 조회해 상태를 표시하고 중복 시작을 막는다. 작업 실패 기록은 `04-Projects/review-queue/queue.json`에 보존한다.

공유 그래프가 다른 작업으로 바뀌면 그 파일은 덮어쓰지 않는다. 검증된 리뷰·논문 JSON·인덱스를 저장하고 해당 논문의 Graphify 상태를 `pending`으로 남긴다. 논문 JSON·리뷰·인덱스 자체의 충돌은 저장을 중단한다. HTML은 다른 논문의 로컬 PDF 링크가 유지되도록 정본 저장 후 실제 라이브러리에서 다시 생성한다.

실제 MOTUS 실행은 CLI 옵션 수정 뒤 리뷰를 작성했다. 최초 저장은 공유 그래프 충돌로 차단됐으며, 보존한 리뷰·JSON을 검증해 복구했다. 리뷰 상태는 `completed`, 그래프 동기화는 `pending`이다.
