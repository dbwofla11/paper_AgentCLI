# 관련 연구 맵핑

앵커 논문 1편을 기준으로 계보를 세운다. 리뷰 §9(관련 연구 속 위치)를 채우거나, 한 주제의 지형을 파악할 때 쓴다.

## 절차

1. **앵커 확정** — arXiv ID 또는 S2 ID. 사용자가 제목만 주면 `paper.py meta`로 ID를 확정한다.

2. **후방 추적 (references)**
   ```bash
   python scripts/paper.py refs <id> --limit 40
   ```
   앵커가 인용한 문헌 중 **앵커의 방법이 직접 딛고 선 것**을 고른다. 인용수 상위가 아니라 앵커 본문에서 방법·비교 대상으로 언급된 것이 기준이다. 판단이 어려우면 PDF의 관련 연구 절을 실제로 읽는다.

3. **전방 추적 (citations)**
   ```bash
   python scripts/paper.py cites <id> --limit 40
   ```
   앵커를 인용한 논문 중 **앵커를 확장하거나 반박한 것**을 고른다. 단순 나열 인용은 뺀다. 인용수와 최신성을 함께 본다 — 앵커를 정면으로 반박한 논문은 인용수가 낮아도 가장 중요하다.

4. **한 단계 더** — 후방·전방에서 특히 중요한 논문 1~2편에 대해서만 재귀한다. 무한 확장하지 않는다.

## 산출물

`notes/{앵커-슬러그}.related.md`:

```markdown
# 관련 연구 맵 — <앵커 논문>
```

## 규칙

- 관계(확장·반박·응용)는 실제 근거로 판정한다. 초록·인용 문맥을 확인하지 않은 채 제목만 보고 관계를 단정하면 `[확인 필요]`를 붙인다.
- API로 확인되지 않은 논문은 표에 넣지 않는다.
- 인용수는 참고 지표다. 최신 논문의 낮은 인용수를 중요도 부족으로 읽지 않는다.
- 표가 20행을 넘어가면 잘라낸 기준을 명시한다.
