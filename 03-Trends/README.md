# 03-Trends — 날짜별 흐름

과거 날짜별 다이제스트와 일일 논문 선정 계획은 [`daily/`](daily/)에 둔다. 현재 일일 논문 후보는 채팅으로만 제시하며, 선정 계획 파일만 날짜별로 저장한다.

트렌드에서 발견한 항목은 다음 중 하나로 보낸다.

- 나중에 읽기: `01-Papers/keep.md` (일일 후보는 사용자가 채택한 뒤 등록)
- 즉시 읽기 판단: `01-Papers/index.md` + 트리아지 메모
- 개념을 이해해야 함: `02-Concepts/`
- 실험할 가설: `05-ideas/` 또는 `04-Projects/`
