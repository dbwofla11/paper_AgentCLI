# On-device Game AI: Budgeted NPC Inference

- 상태: grill-me
- 작성일: 2026-09-18
- 검증 정책: required (method / reproducibility / novelty 독립 심사 후 사용자 결정)
- 진행 정본: `progress.md`

## 문제 상황

게임 내 다수 NPC에 LLM 기반 대화·계획을 적용하면, NPC별 대화 이력과 장기 기억이 프롬프트와 KV cache를 늘리고 동시 호출이 GPU 메모리와 지연시간을 악화시킨다. 양자화만 적용하면 메모리는 줄지만, 어떤 NPC의 어떤 기억·추론 단계를 보존해야 하는지는 해결하지 않는다.

목표 하드웨어는 향후 도입할 RTX 5060과 시스템 RAM 16GB다. GPU VRAM 용량, 대상 게임 장르, NPC가 해야 할 행동 주기는 아직 확인하지 않았다. 따라서 현재 어떤 모델 크기나 절대 지연시간 수치를 가정하지 않는다.

## 잠정 연구 질문

고정된 온디바이스 자원 예산에서, **공유 저정밀 NPC 정책과 중요도 기반 기억·추론 예산 배분**이 독립 NPC별 고정 컨텍스트 방식보다 NPC 정체성(persona)·과업 수행 품질을 보존하면서 피크 메모리와 p95 응답지연을 줄일 수 있는가?

## 잠정 가설과 반증 조건

- H1: 대화·상태의 중요도에 따라 기억 회수량, 컨텍스트 길이, 추론 호출 빈도를 배분하면, 동일 자원 예산에서 고정 균일 배분보다 품질-지연시간 파레토가 개선된다.
- H0 / 반증: 동일 모델·동일 품질·동일 자원 예산에서 균일 배분 기준선이 동등하거나 우수하면, 예산 배분 정책의 기여는 없다.
- 추가 반증: 효율 이득이 NPC 정체성 일관성 또는 게임 과업 성공률의 실질적 저하로만 만들어진다면 채택하지 않는다.

## 관측 가능한 성공 기준 (최종 수치는 기기·장르 확정 후 고정)

1. 동일 품질 기준에서 피크 VRAM 또는 p95 응답지연을 25% 이상 낮춘다.
2. 동일 자원 예산에서 과업 성공률과 persona consistency가 강한 균일 배분 기준선 대비 2%p 이내로 유지되거나 향상된다.
3. 단일 NPC뿐 아니라 동시 NPC 수를 늘린 부하 구간에서도 효과가 재현된다.
4. full-budget 상한선과 비교해 품질 저하가 허용 한계 내인지 별도 보고한다.
5. 모델, 양자화 bit, 프롬프트, seed, NPC 수, 온도 상태, 측정 반복 횟수와 환경을 공개해 재현 가능해야 한다.

## 최소 비교군

1. 독립 NPC + 고정 컨텍스트 + 동일 양자화 모델
2. 공유 모델 + 고정 균일 기억/호출 예산
3. 제안: 공유 모델 + 중요도 기반 예산 배분
4. full-budget 또는 고정밀 모델 상한선

## 아직 필요한 grill-me 입력

- 대상 게임 장르·환경과 NPC의 역할 (대화 / 전략 / 실시간 행동)
- 허용 응답지연과 동시 NPC 수
- RTX 5060의 정확한 VRAM 용량 및 OS 환경
- persona consistency와 과업 성공을 측정할 구체적 평가 과제
- 사용하지 않을 정보·외부 API·클라우드 호출 범위
