## 논문 3편

### 1. Learning to Adapt: Self-Improving Web Agent via Cognitive-Aware Exploration

- 카테고리: 에이전트 AI (Agent AI) · 컴퓨터 비전 (Computer Vision)
- 저자: Weile Chen, Bingchen Miao, Qifan Yu, Wendong Bu, Guoming Wang, Wenqiao Zhang, Shengyu Zhang, Juncheng Li, Siliang Tang.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, pp. 22402–22411. CVF 공식 proceedings가 서지와 Open Access PDF를 제공한다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Chen_Learning_to_Adapt_Self-Improving_Web_Agent_via_Cognitive-Aware_Exploration_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Chen_Learning_to_Adapt_Self-Improving_Web_Agent_via_Cognitive-Aware_Exploration_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../01-Papers/pdfs/agent-ai/2026-chen-scale-web-agent.pdf)

#### 핵심 요약

`SCALE (Self-Cognitive-Aware Learning and Exploration)`은 multimodal large language model(MLLM) 기반 web agent가 expert trajectory나 고정 실행 파이프라인 없이 자기 한계를 탐색하도록 하는 프레임워크다. 같은 MLLM이 `Selector`(도전적 행동 제안), `Predictor`(결과 예측), `Judger`(실행 후 예측 검증) 역할을 수행하며, 이 피드백 루프를 통해 탐색을 갱신한다 (§3.1, PDF pp. 3–4). `SCALE-Hop`은 interaction history를 web state graph로 표현해 덜 탐색된 상태로의 전환을 계획한다 (§3.2, PDF p. 4).

저자들은 19개 실제 웹사이트의 탐색 trace에서 single-step 15,042개, multi-step 3,780개, page-comprehension QA 6,886개로 구성된 `SCALE-20k`를 만들었다 (§3.3, Fig. 3, PDF p. 5). `VisualWebArena`와 `WebVoyager`에서 `Qwen2.5-VL-7B`의 평균 task success rate는 zero-shot 4.1에서 `SCALE` 11.9로, `InternVL2.5-8B`는 1.4에서 4.6으로 제시된다 (Table 1, PDF p. 6).

#### 중요한 이유

[추론] web agent의 학습 데이터를 사람이나 더 강한 모델의 성공 trajectory에만 의존하지 않고, 환경에서 드러난 자체 예측 실패를 데이터와 policy 개선 신호로 삼는다. 그러나 표의 성능은 특정 visual-only input 설정과 네 web domain의 평가 결과이므로, 일반적인 browser automation 안정성으로 확대할 수 없다 (§4.1–4.2, Table 1, PDF pp. 6–7).

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| 세 역할의 adversarial feedback으로 agent가 인지적 한계를 찾아 탐색한다. | Abstract, §3.1, Fig. 2, PDF pp. 1, 3–4 |
| `SCALE-Hop`이 state graph로 global exploration을 보조한다. | §3.2, PDF p. 4 |
| `SCALE-20k`는 19개 실제 웹사이트의 exploration trace에서 구축됐다. | §3.3, Fig. 3, PDF p. 5 |
| 제시된 benchmark에서 backbone의 task success rate가 상승한다. | §4.1–4.2, Tables 1–3, PDF pp. 6–7 |

#### 한계

[내 의견] `WebVoyager`에서는 사이트별 처음 11개 task만 평가했고, 입력에서 accessibility tree와 page description을 제거했다 (§4.1, PDF p. 6). 따라서 접근성 정보가 가능한 실제 agent stack이나 다른 task 분포에서의 효과는 확인되지 않았다 [확인 필요]. 또한 탐색 중 실제 웹사이트의 동적 변화·정책 변경에 대한 장기 재현성은 본문 결과만으로 판단할 수 없다.

### 2. Geometrically-Constrained Agent for Spatial Reasoning

- 카테고리: 컴퓨터 비전 (Computer Vision) · 에이전트 AI (Agent AI)
- 저자: Zeren Chen, Xiaoya Lu, Zhijie Zheng, Pengrui Li, Lehan He, Yijin Zhou, Jing Shao, Bohan Zhuang, Lu Sheng.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, pp. 38689–38699. CVF 공식 proceedings가 서지와 Open Access PDF를 제공한다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Chen_Geometrically-Constrained_Agent_for_Spatial_Reasoning_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Chen_Geometrically-Constrained_Agent_for_Spatial_Reasoning_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../01-Papers/pdfs/computer-vision/2026-chen-gca-spatial-reasoning.pdf)

#### 핵심 요약

`GCA (Geometrically-Constrained Agent)`는 VLM(vision-language model)이 모호한 시각 질의를 바로 tool call로 풀지 않고, 먼저 reference frame과 objective를 담은 formal task constraint $C_{task}$로 변환하게 한다. 이어지는 solver는 그 constraint가 정한 결정론적 범위 안에서 tool call을 생성·실행한다 (§3.1–3.2, Fig. 2, PDF pp. 3–5). 저자들은 이를 training-free agentic paradigm으로 제시한다 (Abstract, §3, PDF pp. 1, 3).

여러 spatial reasoning benchmark에서 GCA의 평균 accuracy는 64.8%로 보고됐으며, 표의 `Gemini-2.5-Pro` foundation baseline보다 12 percentage points, `SpatialLadder`보다 27 points 높다고 저자들이 서술한다 (§4.2, Table 1, PDF p. 6). ablation은 formal constraint가 MMSI-Bench 성능에 기여한다는 분석을 제공한다 (§4.3, Table 2, PDF pp. 6–7).

#### 중요한 이유

[추론] 언어 모델의 의미 해석과 geometry 계산을 한 추론 chain에 섞지 않고, 검증 가능한 constraint라는 중간 산출물로 분리한다. 이 접근은 결과 답만 tool로 검증하는 agent보다 planning 단계의 geometric 오류도 제한하려는 설계다 (§1, §3, PDF pp. 2–5). 다만 논문이 보고한 우위는 해당 benchmark와 tool configuration의 결과다.

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| semantic analyst와 task solver의 2단계로 VLM 역할을 분리한다. | Abstract, §3.1–3.2, Fig. 2, PDF pp. 1, 3–5 |
| $C_{task}$가 이후 계산의 formal·verifiable boundary를 제공한다. | §3.1, PDF pp. 3–4 |
| 여러 spatial benchmark에서 평균 accuracy 64.8%를 보고한다. | §4.2, Table 1, PDF p. 6 |
| constraint 도입의 기여를 ablation으로 제시한다. | §4.3, Table 2, PDF pp. 6–7 |

#### 한계

[내 의견] formal constraint를 VLM이 처음 생성하므로, 모호한 질의의 잘못된 formalization 자체를 완전히 제거하지는 못한다. 또 저자들의 benchmark accuracy는 실제 robotics의 sensing noise, 물체 조작, 안전 제약을 평가하지 않으므로 physical deployment 성능은 [확인 필요]다 (§3–4, PDF pp. 3–7).

### 3. OctoT2I: A Self-Evolving Agentic Text-to-Image Router

- 카테고리: 에이전트 AI (Agent AI) · 컴퓨터 비전 (Computer Vision)
- 저자: Xu Jiang, Bin Chen, Gehui Li, Yule Duan, Ronggang Wang, Jian Zhang.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, pp. 31628–31638. CVF 공식 proceedings가 서지와 Open Access PDF를 제공한다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Jiang_OctoT2I_A_Self-Evolving_Agentic_Text-to-Image_Router_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Jiang_OctoT2I_A_Self-Evolving_Agentic_Text-to-Image_Router_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../01-Papers/pdfs/agent-ai/2026-jiang-octot2i-agentic-text-to-image.pdf)

#### 핵심 요약

`OctoT2I`는 text-to-image(T2I) generation을 quality와 inference cost의 공동 최적화로 두고, 여러 생성 tool 중 다음 tool을 다중 라운드로 고르는 router agent를 제안한다 (§3.1–3.2, PDF pp. 3–4). 긴 기억 `K`는 prompt exploration의 Pass@1과 tool의 capability·cost profile을 축적하고, 짧은 기억 `M`은 현재 prompt의 tool·score·image history를 보관한다. decision policy는 quality threshold를 충족할 것으로 예측한 tool 중 최저 cost tool을 선택한다 (Eqs. 4–7, §3.2, PDF pp. 4–5).

tool capability frontier는 human annotation 없이 `Propose–Solve–Evaluate–Learn (PSEL)` loop로 탐색한다 (§3.3, PDF pp. 5–6). `GenEval`에서 overall score 0.96, `T2I-CompBench++`에서 average 0.6618을 보고했으며, 표의 `Flow-GRPO`는 각각 0.93과 0.6332다 (Tables 1–2, PDF pp. 6–7). 같은 efficiency table에서 average inference time은 10.02 s, `Flow-GRPO`는 19.07 s로 제시된다 (Table 3, PDF p. 7).

#### 중요한 이유

[추론] T2I 성능 개선을 단일 generator의 parameter scaling이 아니라 task별 tool routing 및 지속적인 capability measurement로 바꾼다. quality metric만이 아니라 latency·CO2e·energy를 같은 표에 포함한 점도 agent system의 운영 비용을 평가 대상으로 만든다 (Tables 1–3, PDF pp. 6–7). 단, 모든 tool의 품질·비용 추정이 바뀌면 router의 결정도 달라질 수 있다.

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| stateful multi-round router가 quality와 cost를 함께 고려한다. | Abstract, §3.1–3.2, Eqs. (4)–(7), PDF pp. 1, 3–5 |
| PSEL이 human supervision 없이 tool capability frontier를 탐색한다. | Abstract, §3.3, PDF pp. 1, 5–6 |
| `GenEval` 0.96 및 `T2I-CompBench++` 0.6618을 보고한다. | §4.1–4.2, Tables 1–2, PDF pp. 6–7 |
| 비교 agentic method보다 낮은 표의 average inference time을 보고한다. | §4.2, Table 3, PDF p. 7 |

#### 한계

[내 의견] quality threshold와 evaluation function의 오차는 router가 잘못된 tool을 싸다고 선택하게 할 수 있으나, threshold가 달라지는 deployment 조건의 failure rate는 표에서 확인하지 못했다 [확인 필요] (§3.2, §4.3, PDF pp. 4–8). 또 저자들이 사용한 benchmark·default tool setting을 벗어난 proprietary model 변경과 가격 변동에 대한 재현성은 미기재다 (§4.1, PDF p. 6).

## 시사이슈 3건

### 1. Anthropic의 `ART` 후보 효소계 공개

- 날짜: 2026-09-23
- 출처: [Anthropic 공식 Science 발표](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) · 발표문 내 기술 보고서 링크
- 원문 링크: [Claude discovers a novel enzyme system with CRISPR-like repeats](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system)

#### 핵심 요약

Anthropic은 Claude agent가 200,000개 이상의 reverse transcriptase(RT)를 모으고 3,500개 candidate system에서 20개를 추려 분석한 뒤, RT·인접 partner gene·DNA repeat array로 구성된 `ART (array-associated reverse transcriptases)` 후보를 찾아냈다고 발표했다 (Anthropic, 2026-09-23). 회사는 약 950 agent가 21시간 동안 210 million token을 사용했다고 밝히며, ART의 primary function은 아직 조사 중이라고 명시한다 (같은 출처).

#### 중요한 이유

[추론] agent를 hypothesis generation·candidate triage·human laboratory review의 연결 단계에 쓰는 사례다. 다만 이는 회사 발표와 preprint 단계의 초기 결과이며, ART의 기능·재현성·응용 가능성은 확정되지 않았다 [확인 필요] (Anthropic, 2026-09-23).

### 2. OpenAI의 `GPT-6 Sol`·`GPT-6 Luna` 출시 및 API 가격 변경

- 날짜: 2026-09-22
- 출처: [OpenAI 공식 제품 발표](https://openai.com/index/introducing-gpt-6-sol-and-luna/) · [공식 system card 링크](https://deploymentsafety.openai.com/)
- 원문 링크: [Introducing GPT-6 Sol and Luna](https://openai.com/index/introducing-gpt-6-sol-and-luna/)

#### 핵심 요약

OpenAI는 `GPT-6 Sol`과 `GPT-6 Luna`를 발표하고, API 입력·출력 가격을 각각 `GPT-5.6 Sol`의 $4/$20에서 $2/$10, `GPT-5.6 Luna`의 $0.20/$1.20에서 $0.10/$0.50(모두 1 million token당)으로 제시했다 (OpenAI, 2026-09-22). 발표에 따르면 두 모델은 ChatGPT Work·Codex 및 API에서 `gpt-6-sol`, `gpt-6-luna`로 제공되며, ChatGPT 내 rollout은 점진적으로 진행된다 (같은 출처).

#### 중요한 이유

[추론] agent를 장시간 반복 실행할 때 token price와 prompt-cache hit rate가 전체 운영비를 크게 좌우하므로, capability보다 cost–latency tier를 분화하는 제품 변화다. benchmark·경쟁 모델 비교 수치는 OpenAI의 자체 발표이므로, 독립 재현으로 해석해서는 안 된다 [확인 필요] (OpenAI, 2026-09-22).

### 3. OpenAI의 Ukraine civilian cyber defense용 `Daybreak` 접근 확대

- 날짜: 2026-09-23
- 출처: [OpenAI 공식 발표](https://openai.com/index/openai-extends-cyber-access-to-ukraine-for-civilian-defense/) · [CERT-UA 통계 링크](https://info.poda.gov.ua/)
- 원문 링크: [OpenAI extends cyber access to Ukraine for civilian defense](https://openai.com/index/openai-extends-cyber-access-to-ukraine-for-civilian-defense/)

#### 핵심 요약

OpenAI는 Ukraine 정부에 `Daybreak` program 접근을 제공해 civilian infrastructure의 software vulnerability 식별과 fix 개발·검증을 지원하겠다고 발표했다 (OpenAI, 2026-09-23). 회사는 Ukraine의 CERT-UA가 2025년에 약 6,000건의 cyber incident를 처리했다고 인용했으며, `Daybreak`의 용도를 authorized security work로 한정했다 (같은 출처).

#### 중요한 이유

[추론] frontier AI의 cybersecurity deployment가 일반 제품 기능에서 국가 critical infrastructure의 authorized defensive operation으로 확장되는 사례다. 다만 실제 취약점 감소나 인프라 resilience의 효과는 발표 시점에 검증되지 않았으며 [확인 필요], 지원 범위·성과는 향후 독립 자료가 필요하다.
