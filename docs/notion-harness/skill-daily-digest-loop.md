# 일일 논문 후보 · daily-digest-loop

## 역할

CV·멀티모달·관심 분야 각 후보 한 편을 채팅으로 제시

## 입력

오늘 날짜·선정 계획·사용자 관심 맥락

## 작동 조건·결과

스킬 호출당 탐색만 수행한다. 반복 실행 시각은 Orca, 날짜별 주제는 paper-scheduler가 관리한다.
