# 사고실험

## 역할

아이디어를 질문과 반증 조건이 있는 기획으로 바꾼다. 비판적 사고, Grill-me, 독립 심사, 사용자 의견 반영을 이 페이지 아래에서 관리한다.

## 각 하네스가 하는 일

- thought-experiment-critique: 전제·누수·식별가능성·대체 설명을 처음 점검한다.
- critical-validation: Grill-me로 사용자 답변을 brief에 반영하고, 문헌과 동일 근거 묶음을 준비한다.
- method / repro / novelty critic: 같은 근거를 각 관점에서 독립적으로 비판한다.
- idea_analysis.py: 근거 해시·역할 완결성·판정·사용자 결정 일관성을 검사한다.
- thought-experiment-runner: 승인된 계획만 작은 실험과 실행 증거로 연결한다.

## 사용자 의견 반영

핵심 가설·성공/반증 조건은 사용자 승인 뒤 심사한다. 보완 요청은 다시 Grill-me로 돌아간다. 근거가 변경되면 동결 버전과 기존 심사를 갱신한다. 최종 진행·보류·폐기는 사용자가 결정한다. 매 실험마다 자동 질문하는 주기는 별도로 정의되어 있지 않다.

## 현재 적용 범위

mode는 required다. 세 페르소나는 분야 공통이며 분야별 전문 페르소나는 없다. 일반 논문 리뷰에 세 독립 심사가 자동 적용되는 상태도 아니다.
