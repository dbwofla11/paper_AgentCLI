# 논문 검색·수집 · paper-search

## 역할

출처·중복·분야를 확인하고 PDF·Keep·인덱스·JSON으로 등록

## 입력

PDF·제목·링크·arXiv ID 또는 채택한 후보

## 작동 조건·결과

검색 후보만 요청하면 저장하지 않는다. 원문과 공식 메타데이터를 우선하고 검색 한계를 보고한다.
