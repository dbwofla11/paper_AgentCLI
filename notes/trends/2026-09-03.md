## 논문 3편

### 1. User Representation via Cross Multi-source Behavior Pre-training for Mobile Games

- 출처: Chengqi Yang 외 9명, arXiv:2609.01057v1, 2026-09-01 제출. IEEE ICDM 2026 regular paper로 게재 예정이라고 메타데이터에 기재되어 있다 (arXiv 메타데이터; §Abstract, p.1).
- 원문: [arXiv 공식 페이지](https://arxiv.org/abs/2609.01057) · [원문 HTML](https://arxiv.org/html/2609.01057v1) · [원문 PDF](https://arxiv.org/pdf/2609.01057)

#### 초록

모바일 게임 추천에서 서로 다른 출처와 시간적 세분화(granularity)를 가진 행동 시퀀스를 함께 사전학습해 사용자 표현을 만드는 문제를 다룬다. 논문은 세 가지 행동 출처의 신호를 통합하는 `CM-PTM`을 제안하고, 게임 추천 시나리오에서 기존 사전학습·추천 모델과 비교한다 (§Abstract, p.1).

#### 전체적인 주장

출처 간 행동을 단순히 하나의 시퀀스로 합치기보다 출처별·세분화별 구조를 보존하고, 다음 행동의 출처와 세부 행동을 계단식으로 예측하면 사용자 표현의 추천 성능이 좋아진다는 주장이다. 오프라인 실험에서 `CM-PTM`은 6개 게임 시나리오 중 5개에서 비교 대상 중 최고 AUC를 기록했고, OPPO 온라인 A/B 테스트에서도 개선을 보고했다 (§IV, §V-B–F, Tables III–V).

#### 메소드

입력은 OPPO 기기에서 수집한 `GameApps`, `Appstore`, `Gamecenter`의 다중 출처·다중 세분화 행동 시퀀스다. `GASA`(Granularity-Aware Self-Attention)가 같은 출처의 세분화별 신호를 처리하고, `CGFA`(Cross-Granularity Fusion Attention)가 출처 간 정보를 융합한다 (§IV-A, Eq.1–6, pp.3–4). 사전학습은 먼저 다음 행동의 출처를 예측한 뒤, `Appstore`에서는 앱 카테고리와 App ID를, 게임 행동에서는 가능한 경우 operation을 예측하는 계단식(cascaded) 구조다. 전체 손실은 $L=\lambda L_{INTER}+(1-\lambda)L_{INTRA}$로 정의된다 (§IV-B–C, Eq.7–11, pp.4–5).

사전학습 표현과 프로필 특성을 downstream 입력으로 사용하고, 논문은 표현을 고정하거나 미세조정한 뒤 `LightGBM`을 사용한다고 설명한다. 임베딩 차원은 64, 사용자 표현 차원은 $6\times64$, batch size는 512, learning rate는 $10^{-4}$, 최대 시퀀스 길이는 256, attention head 수는 2, $\lambda=1/2$이며 학습·검증 분할은 9:1이다 (§V-A, p.5). 데이터는 익명화된 OPPO 기기 로그의 앞선 180일을 사용했고, 사전학습 주간에는 1,947,683명과 83,341개 앱이 포함된다 (§V-A, Table I, p.5).

#### 실험·결과

G1–G6의 6개 게임 추천 시나리오에서 평가했다. `CM-PTM`의 AUC는 G1–G5에서 각각 0.8542, 0.8411, 0.8976, 0.8724, 0.9056이었고, G6에서는 0.9859였다. Table III의 최고 baseline 대비 개선 행에서 AUC 개선폭은 G1–G6 순서로 각각 +1.72%, +2.85%, +1.05%, +1.34%, +1.08%, −0.08%이며, `R@P.95` 개선폭은 +1.48%, +2.55%, +1.23%, +2.10%, +0.73%, +0.87%다 (Table III, pp.6–7). 즉 G6에서는 AUC가 최고 baseline보다 낮지만 `R@P.95`는 개선됐다.

구성요소 제거 실험에서는 fine-grained 행동을 제거할 때 G1·G5 AUC가 각각 2.64 및 2.39 percentage points 낮아졌고, 출처별 시퀀스를 하나로 합치거나 계단식 예측을 병렬 예측으로 바꾸는 경우도 성능이 하락했다 (§V-C, Table IV, p.7). 온라인 테스트는 2025-01-05~18 동안 2,890,000명의 active users를 균등 분할해 `DeepFM`과 비교했으며, AUC 1.28%, `R@P.95` 1.07% 개선을 보고했다 (§V-F, Table V, p.8).

#### 한계

저자는 짧은 시간 창의 상대 순서에 positional embedding만 사용했다는 점, 행동 출처가 세 종류로 고정되어 있고 third-party app 행동이 coarse event에 머문다는 점, 개인정보·윤리 문제를 한계와 향후 과제로 언급한다 (§VI, pp.9–10). 모든 데이터와 온라인 검증이 OPPO 환경과 6개 게임 시나리오에 묶여 있으므로 다른 제조사·지역·게임 생태계로의 일반화는 이 논문만으로 확인되지 않는다 `[추론]` (Table I–V, §VI).

#### 중요한 이유

이 논문은 모바일 게임 추천의 사용자 표현을 단일 행동 로그가 아니라 출처·세분화·예측 순서가 있는 구조로 다룬다. 따라서 여러 앱·게임 서비스의 이질적인 행동 로그를 통합해야 하는 추천 시스템에서, 어떤 정보를 보존하고 어떤 사전학습 과제를 설계할지에 대한 구체적인 설계 선택과 ablation 근거를 제공한다 (§IV–V). 다만 보고된 이득은 OPPO의 고정된 데이터·서비스 구성에서 측정된 결과다.

### 2. WirelessSenseLLM: Zero-Shot Human Activity Understanding by Bridging Wireless Signals and Human Language

- 출처: Mahmuda Keya, Sneh Pillai, Jiawei Yuan, Kai Zeng, Long Jiao, arXiv:2605.14070v1, 2026-05-13 제출. IEEE SECON 2026 게재 예정이라고 메타데이터에 기재되어 있다 (arXiv 메타데이터; §Abstract, p.1).
- 원문: [arXiv 공식 페이지](https://arxiv.org/abs/2605.14070) · [원문 HTML](https://arxiv.org/html/2605.14070v1) · [원문 PDF](https://arxiv.org/pdf/2605.14070)

#### 초록

WiFi CSI를 사람의 행동을 설명하는 자연어와 연결해, 학습 때 보지 않은 행동에 대한 zero-shot human activity understanding을 시도한다. 제안 시스템은 wireless signal encoder, `CSI-to-Language Adapter`, cross-domain projection, `Vicuna-7B v1.5`를 결합하고 single-person과 multi-person 장면을 모두 평가한다 (§Abstract, §I, pp.1–2).

#### 전체적인 주장

CSI를 별도의 행동 분류기 출력으로만 다루지 않고 언어 모델이 처리할 수 있는 표현으로 투사하면, 제한된 행동 라벨에 의존하지 않고 행동 설명과 다중 인원 추론을 수행할 수 있다는 주장이다. 논문이 정의한 zero-shot 설정은 평가 행동을 학습에서 제외하고, 명시적인 action-specific segmentation/label을 사용하지 않는 조건이다 (§V-B, Table II, p.6).

#### 메소드

채널 모델에서 사람의 움직임이 CSI의 amplitude와 phase를 변화시킨다고 두고, 입력 CSI를 $Y_i\in\mathbb{R}^{180\times60}$으로 구성해 $180\times256$ 표현으로 투사한다. 2-layer MLP와 `GELU` 기반 adapter가 wireless representation을 text embedding 공간에 맞추며, 1단계에서는 text encoder를 고정하고 adapter만 contrastive loss로 학습한다 (§III-A–B, Eq.1–4, pp.2–3). 2단계에서는 cross-modal projection과 `LoRA`를 사용해 언어 모델이 CSI와 대응하는 텍스트를 생성하도록 미세조정한다 (§III-B, §IV, Eq.5, pp.3–4).

학습 데이터는 `Wireless-Text`, `Video-Text`, `Text` 세 묶음이다. `Wireless-Text`에는 89,946 train, 7,824 test, 총 97,000개가, `Video-Text`에는 22,588 train, 36,619 test, 총 25,098개가, `Text`에는 2,510 train, 4,069 test, 총 40,688개가 표에 기재되어 있다. CSI는 300 packets/s, 영상은 15 fps로 동기화했으며, 주석 초안은 `LLaVA Next`와 `GPT-4`가 만들고 사람이 검토했다 (§IV-A, Table I, p.5).

#### 실험·결과

zero-shot 기본 설정에서 accuracy 67%, F1 65%를 기록했고, in-context learning에서는 89%/87%, chain-of-thought에서는 92%/91%를 기록했다. 비교 baseline들의 accuracy 범위는 14–40%, F1 범위는 13–33%로 보고됐다 (§V-B, Table II, p.6). 한 사람 장면의 언어 생성 평가에서 전체 `WirelessSenseLLM`은 ROUGE-1 0.3352, ROUGE-L 0.2376, BLEU 0.0379, METEOR 0.1937, BERTScore 0.8800을 기록했고, 비교 모델 `Video-LLaVA`는 각각 0.2996, 0.1999, 0.0284, 0.1671, 0.8638이었다 (§V-C, Table IV, p.7).

다중 인원 장면에서 모델의 전체 점수는 2명 44.78%, 3명 35.65%, 4명 21.54%였고, 비교 baseline은 각각 26.52%, 20.00%, 18.46%였다. 논문은 차이를 각각 18.26, 15.65, 3.08 percentage points로 요약한다 (§V-C, Table V, p.7).

#### 한계

장면 복잡도가 증가하면 성능이 낮아지고, 사람 간 상호작용 추론이 어렵다고 저자가 명시한다. 또한 평가는 특정 sensing configuration과 제한된 환경에 집중되어 있으며, 더 넓은 연속 CSI baseline과 효율적인 추론은 향후 과제로 남아 있다 (§VI, p.7). Figure와 방법 설명은 영상이 학습 데이터 구성에 쓰인다고 설명하지만, 실제 추론 단계에서 대응 영상이 항상 필요한지에 대한 분리가 충분히 명확하지 않다 `[확인 필요]` (§III-B–IV, Eq.5, pp.3–4).

#### 중요한 이유

이 연구는 WiFi CSI sensing을 고정된 행동 클래스 예측에서 자연어 기반의 개방형 이해(open-ended understanding)로 확장하려는 구체적인 multimodal 연결 방법을 제시한다. 특히 wireless-to-language adapter와 zero-shot·다중 인원 평가를 함께 제시했다는 점이 중요하다 (§III–V). 그러나 성능 비교는 논문이 선택한 데이터·센서 구성과 baseline에 한정되며, 다른 CSI 수집 조건에서도 같은 수준의 zero-shot 일반화가 성립하는지는 확인되지 않았다 `[확인 필요]`.

### 3. MU-SHOT-Fi: Self-Supervised Multi-User Wi-Fi Sensing with Source-free Unsupervised Domain Adaptation

- 출처: Ahmed Y. Radwan, Hina Tabassum, arXiv:2605.01369v2, 2026-05-21 개정. `IEEE Internet of Things Journal` Early Access 2026 및 DOI `10.1109/JIOT.2026.3686090`가 메타데이터에 기재되어 있다 (arXiv 메타데이터; §Abstract, p.1).
- 원문: [arXiv 공식 페이지](https://arxiv.org/abs/2605.01369) · [원문 HTML](https://arxiv.org/html/2605.01369v2) · [원문 PDF](https://arxiv.org/pdf/2605.01369) · [공식 코드 저장소](https://github.com/AhmedRadwan02/mu-shot-fi)

#### 초록

여러 사람이 동시에 존재하는 WiFi sensing에서 source-free unsupervised domain adaptation(`SFUDA`)을 수행하는 `MU-SHOT-Fi`를 제안한다. 소스 데이터에 다시 접근하지 않고 target domain에서 backbone을 적응하며, occupancy-weighted information maximization과 binary rotation prediction self-supervision을 결합한다. single-user 설정에는 `SU-SHOT-Fi`를 제시한다 (§Abstract, pp.1–2).

#### 전체적인 주장

방·주파수·사용자·하드웨어·시간이 달라질 때 발생하는 domain shift와 다중 사용자 신호의 entanglement를, 라벨 없는 target 데이터와 self-supervised objective로 완화할 수 있다는 주장이다 (§I–II). 결과는 모든 지표에서 균일한 우위라기보다, 특히 slotwise accuracy와 occupancy 지표에서 심한 domain shift를 완화하는 효과를 보여준다 (§VI, Table IV).

#### 메소드

다중 사용자 문제를 최대 6개 사용자 slot과 9개 activity 및 no-person 상태로 표현하고, 예측된 slot과 ground truth slot은 Hungarian matching으로 정렬한다. adaptation 중 classifier를 고정하고 backbone을 업데이트하는 SHOT 계열 구조에 occupancy-weighted information maximization을 추가해 no-person 예측이 다수를 차지하는 데 따른 collapse를 줄인다. 여기에 binary rotation prediction을 self-supervised 보조 과제로 사용하며, single-user 변형은 standard information maximization과 contrastive predictive coding(`CPC`)을 사용한다 (§III–V, Eq.1–20).

`WiMANS`의 다중 사용자 데이터와 `Widar 3.0`의 single-user 데이터를 사용했다. WiMANS는 0–5명, 9개 활동, 2.4/5 GHz, 3×3 MIMO, 1000 Hz, 30 subcarriers, 3초 구간을 포함한다고 설명된다. 다중 사용자 평가는 `Cross-Room`, `Cross-Frequency`, `Combined Shift`로 구성된다 (§VI-A, pp.9–10). 지표는 slotwise accuracy, Activity Macro-F1, Exact Match, occupancy MAE, occupancy Exact Match다 (§VI-B, p.10).

#### 실험·결과

비교 대상은 `Source-only`, `SHOT-IM`, `SHOT++`다. Table IV의 다중 사용자 결과에서 `Combined Shift`의 slot accuracy는 Source-only 19.61에서 `MU-SHOT-Fi` 41.97로, occupancy MAE는 3.00에서 2.12로 개선됐다. `Cross-Frequency`에서도 slot accuracy가 21.16에서 46.97로 증가했다. 반면 평균 Activity Macro-F1은 Source-only 22.19, `MU-SHOT-Fi` 18.12로 낮고, Exact Match는 각각 0.71과 2.88이다. 따라서 activity F1 하나만으로 모델을 평가하면 안 되며, 논문도 과잉 예측이 F1을 높일 수 있어 occupancy 지표와 함께 봐야 한다고 설명한다 (§VI-C, Table IV, pp.10–11).

ablation에서 CPC를 추가한 변형은 `Cross-Room` Exact Match가 7.76에서 6.34로, `Combined Shift` slot accuracy가 41.97에서 41.58로 낮아졌다. 저자 분석에 따르면 query decoder가 no-person 상태를 활용할 수 있어 activity F1이 낮아지는 경우도 있다 (§VI-D–E, Table V, pp.11–12).

#### 한계

가장 큰 성능 이득은 Combined Shift의 slotwise·occupancy 지표에 집중되고, Exact Match와 Activity Macro-F1에서는 절대 성능이 낮거나 Source-only보다 낮은 경우가 있다. 따라서 이 논문은 다중 사용자 activity를 전반적으로 해결했다고 말할 근거를 제공하지 않는다 `[추론]` (Table IV–V). 평가가 `WiMANS`·`Widar 3.0`과 논문에서 정한 실험적 domain shift에 한정되므로, 실제 주거·사무실 환경과 다른 센서 배치·프로토콜로의 일반화는 확인되지 않았다 `[추론]` (§VI, Table I–IV).

#### 중요한 이유

WiFi CSI 연구에서 target 라벨과 source 원본 데이터가 모두 없는 현실적인 배포 조건을 직접 다룬다. 특히 여러 사람의 존재 여부와 slot 정렬을 함께 평가해, 단순 activity classification accuracy보다 배포 환경의 인원 수·점유 추정까지 포함한 평가 설계를 보여준다 (§III, §VI). 다만 지표별 방향이 일치하지 않으므로, 후속 연구는 activity recognition과 occupancy estimation 사이의 trade-off를 분리해 보고해야 한다.
