# 00-Inbox — 빠른 캡처

분류하기 전의 질문, 링크, 한 줄 관찰만 넣는다. 오래 보관하는 노트가 아니다.

## 파일 규칙

- 파일명: `YYYY-MM-DD-짧은-주제.md`
- 한 항목에는 출처(있다면), 왜 남겼는지, 다음 분류 위치만 적는다.
- 처리 뒤에는 삭제하지 말고 해당 영역으로 **이동**한다.

## 분류 기준

- 특정 논문을 읽을지 판단: `library/keep.md` 또는 `notes/`의 트리아지 메모
- 내가 이해한 내용을 설명: `02-Concepts/`
- 검증할 연구 가설: `05-ideas/`
- 실제로 실행할 실험/구현: `04-Projects/`
