## 심사 통과 기준

각 후보는 아래 둘을 모두 만족해야 한다.

1. **차별성**: 보관 논문이 이미 직접 해결한 문제·핵심 메커니즘의 단순 재조합이 아니며, 최소 하나의 명확한 구별점이 있다.
2. **문제 적합성**: 제안 기제가 서술한 병목을 직접 측정·완화할 수 있고, 동일 자원 조건의 대조군과 반증 조건이 있다.

둘 중 하나라도 치명적 결함이면 후보는 폐기 또는 재구성한다.

## 후보 1 — 호출 빈도만 줄이는 Event-triggered LLM NPC

- 문제 상황: NPC가 매 틱 또는 고정 주기로 LLM을 호출해, 실제로는 변하지 않은 상태에서도 지연시간과 VRAM/KV cache 비용을 낸다.
- 가설: 게임 이벤트가 있을 때만 LLM을 호출하고 그 외에는 FSM/RL이 행동하면 품질을 유지하며 비용을 줄인다.
- 성공: 동일 게임 과업·persona 품질에서 LLM 호출 수와 p95 지연시간을 줄인다.
- 반증: 고정 주기 호출이 같은 호출 예산에서 동등하거나 더 좋은 품질이면 기각한다.
- 잠정 위험: Nair & Karim은 5초마다 전략 태그를 고르는 구조를 이미 다뤘고, MASMP는 상태기계 기반 결정을 다룬다. 차별성이 약할 수 있다.

## 후보 2 — 다수 NPC의 VRAM 공정 스케줄러

- 문제 상황: 동시에 여러 NPC가 중요한 결정을 요구하면, 선착순 LLM 호출은 일부 NPC의 지연시간을 폭증시키고 게임 상호작용의 공정성·일관성을 해친다.
- 가설: 이벤트 중요도와 대기 시간을 함께 이용해, 매 시점에 LLM 호출·프롬프트 길이·기억 회수량을 배분하면 동일 자원에서 최악 NPC의 p95 지연시간을 낮출 수 있다.
- 성공: 동일 평균 호출 예산에서 강한 FIFO/균일 배분보다 최악 그룹의 p95 지연시간을 낮추고, NPC별 과업·persona 품질 하락을 제한한다.
- 반증: FIFO/균일 정책이 같은 품질-지연시간 파레토를 달성하거나, 중요도 추정 오차가 품질을 악화시키면 기각한다.
- 잠정 구별점: PCSP는 공유 RL 정책으로 다수 persona를 제어하지만, 런타임 LLM 요청의 다수 사용자 스케줄링 문제는 초록·서론 범위에서 직접 다루지 않는다. [확인 필요]

## 후보 3 — Persona-preserving Memory Compression

- 문제 상황: 경량화를 위해 NPC 기억을 요약·삭제하면 동일 인물의 선호·약속·관계가 섞이거나 사라져, 메모리는 작아져도 NPC가 캐릭터성을 잃는다.
- 가설: 사실·관계·성격 제약을 분리해 저장하고, persona 제약을 만족하는 요약만 허용하면 동일 메모리 예산에서 일반 요약보다 NPC 정체성을 더 보존한다.
- 성공: 같은 토큰/메모리 예산에서 persona consistency와 장기 퀘스트 회상 정확도가 일반 요약보다 높다.
- 반증: 일반 요약/최근 대화 창이 동등하면 기각한다.
- 잠정 위험: MASMP의 경량 전략 메모리와 PCSP의 persona conditioning이 이미 상당 부분을 포괄할 수 있다. 단순 typed memory만으로는 자명한 조합일 수 있다.

## 후보 4 — Risk-aware Hybrid NPC Controller

- 문제 상황: 모든 NPC 행동을 LLM에 맡기면 느리고 환각 행동 위험이 있으며, 모든 행동을 FSM/RL에 맡기면 낯선 플레이어 전략·서사 분기에 적응하지 못한다.
- 가설: 가벼운 정책이 행동 후보와 위험/불확실성을 내고, 실패 비용이 큰 행동만 LLM 검증·재계획으로 올리면 동일 지연시간 예산에서 순수 LLM보다 안전하고 순수 FSM/RL보다 적응적이다.
- 성공: 동일 자원에서 invalid action·치명적 실패를 줄이면서 적응 과업 성공률을 유지 또는 개선한다.
- 반증: 위험 예측기가 오탐 때문에 LLM을 계속 호출하거나, LLM 검증이 실패를 줄이지 못하면 기각한다.
- 잠정 구별점: Nair & Karim은 LLM이 5초마다 네 전술 태그 중 하나를 택하고 공유 PPO가 실행한다. 이 후보는 행동 수준의 위험 기반 승격·검증을 주장하므로 직접 동일하지 않을 수 있다. [확인 필요]

## 후보 5 — Quantization-aware NPC Decision Routing

- 문제 상황: 저비트 LLM은 경량화에 유리하지만, 모든 게임 결정에 같은 bit-width/모델을 적용하면 복잡한 협상·장기 계획에서의 오류와 단순 상태 갱신에서의 낭비를 동시에 만든다.
- 가설: 결정 유형·불확실성에 따라 작은 저비트 모델, 큰 저비트 모델, 비생성 정책 중 하나로 라우팅하면, 단일 고정 양자화 모델보다 품질-비용 파레토가 좋아진다.
- 성공: 동일 VRAM·지연시간 예산에서 행동/대화 품질을 유지하면서 평균 에너지 또는 지연시간을 줄인다.
- 반증: 라우터 비용과 모델 전환 비용을 포함하면 고정 모델보다 이득이 없으면 기각한다.
- 잠정 위험: QuIP#/QTIP/GSQ는 일반 저비트 품질·실용성 문제를, 여러 게임 에이전트 연구는 모델/도구 라우팅을 다룰 수 있다. 게임별 차별성과 실제 전환 비용 검증이 핵심이다. [확인 필요]

## 최소 심사 입력·대조군

- Nair & Karim의 fixed-period LLM strategy selector, MASMP의 state machine + memory, PCSP의 shared persona-conditioned RL policy를 최소 비교 근거로 사용한다.
- 양자화 후보는 QLoRA·QuIP#·QTIP·GSQ가 다루는 범위(모델 압축/추론 실용성)와 게임 런타임 정책을 분리해 판단한다.
- VideoQA 논문은 게임 NPC 선행연구가 아니므로, 직접 신규성 근거가 아니라 “예산 기반 정보 선택”이 일반적으로 알려진 방향인지 점검하는 보조 근거로만 쓴다.
