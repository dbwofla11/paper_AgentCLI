# 발표·디자인·문서 원본 묶음

## 역할

설계 배경과 발표자료 계획·페이지별 내용·노트북 출력 기록, 적용한 디자인 안내는 원본 묶음에 포함한다. 운영 방법은 위 기능별 페이지와 현재 정본을 우선한다. 원본 묶음은 안내 문서·스킬·템플릿·스키마만 포함하며 개인 인증, 논문 PDF, 연구 결과 데이터는 포함하지 않는다.
