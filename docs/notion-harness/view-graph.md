# 지식 그래프 탐색 화면

## 역할

논문·개념·주장 사이 관계 후보를 찾아보는 Graphify의 시각화다. 자체 출력 정본은 graphify-out/graph.html이며 직접 만든 세 운영 화면과 저장 위치가 다르다. 그래프 연결은 원문 증거를 대신하지 않는다. 관계 확정은 paper-relations와 원문 확인을 따른다.
