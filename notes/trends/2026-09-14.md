## 논문 3편

### 1. Experience Transfer for Multimodal LLM Agents in Minecraft Game

- 카테고리: 게임 AI (Game AI) · 에이전트 AI (Agent AI)
- 저자: Chenghao Li, Jun Liu, Songbo Zhang, Huadong Jian, Hao Ni, Lik-Hang Lee, Sung-Ho Bae, Guoqing Wang, Yang Yang, Chaoning Zhang.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, regular paper, pp. 37143–37153. CVF Open Access proceedings 페이지와 PDF의 서지정보로 게재를 확인했다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Li_Experience_Transfer_for_Multimodal_LLM_Agents_in_Minecraft_Game_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Li_Experience_Transfer_for_Multimodal_LLM_Agents_in_Minecraft_Game_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../papers/2026-li-experience-transfer-multimodal-llm-minecraft.pdf)

#### 핵심 요약

저자들은 `Minecraft`의 새 과제에서 과거 경험을 단순 trajectory 저장소로 쓰는 대신, `Echo`라는 transfer-oriented memory framework를 제안한다. 재사용할 지식을 structural, attribute, procedural, functional, interaction의 다섯 축으로 분해하고, multimodal state를 `Contextual State Descriptor (CSD)`로 정리한 뒤 `In-Context Analogy Learning (ICAL)`으로 유사 사례를 검색·적응한다 (Abstract, §3.1–3.3, PDF pp. 1, 4–6).

평가는 Recipe, Functional Equivalence, Crafting Chain, Utility Blocks의 네 task family에서, episode 0–10 및 0–30의 평균 성공률(`Success@0→10/30`)을 비교한다 (§4.1, PDF p. 6). 예를 들어 `Echo (8-shot)`은 Recipe의 Bed에서 62.5/92.5, Iron Pickaxe에서 52.5/87.5를 기록했고, Crafting Grid에서는 57.5/92.5를 기록한다 (Table 1, PDF p. 6). 초록은 object-unlocking task에서 이전 방법 대비 1.3–1.7배의 속도 향상을 보고한다 (Abstract, PDF p. 1).

#### 중요한 이유

[추론] 장기 메모리를 많이 저장하는 것과 새 과제에 전이할 수 있는 지식을 표현하는 것은 다르다. 이 연구는 전이를 다섯 축과 사례 기반 추론의 명시적 구성요소로 만들었으므로, 게임 환경에서의 장기 agent memory를 “검색”뿐 아니라 “유추 가능한 state abstraction”의 문제로 다룬다 (§3.1–3.3, PDF pp. 4–6). 다만 이 결론은 `Minecraft` crafting·equivalence task와 논문이 정한 episode 범위에 한정된다 (§4.1, Table 1, PDF p. 6).

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| 다섯 transfer dimension과 CSD를 통해 multimodal 경험을 비교 가능한 상태 표현으로 정리한다. | Abstract, §3.1–3.2, Figs. 4–5, PDF pp. 1, 4–5 |
| ICAL이 유사 경험을 찾아 새 task 계획에 사례로 제공한다. | §3.2–3.3, Fig. 6, PDF pp. 5–6 |
| few-shot 설정에서 여러 Minecraft task family의 성공률을 제시한다. | §4.1, Table 1, PDF p. 6 |
| 연속 학습에서 초기에는 느리지만 episode 10 이후 성장이 빨라지고, 마지막 단계에서 약 46–48% plateau를 보인다고 분석한다. | §4.2, Fig. 8, PDF pp. 7–8 |

#### 한계

[내 의견] 평가가 `Minecraft`의 수작업 설계 task와 특정 item/crafting 관계에 집중되므로, 웹·로봇 등 다른 환경에서 다섯 축이 같은 방식으로 transfer를 포착한다는 실증은 없다 (§4.1, PDF p. 6). 또한 1·2·4·8-shot 비교는 contextual example 수를 함께 바꾸므로, 각 축 자체의 효과와 context budget 효과를 완전히 분리하지는 않는다 (Table 1, §4.3, PDF pp. 6, 8) [확인 필요].

### 2. Training One Model to Master Cross-Level Agentic Actions via Reinforcement Learning

- 카테고리: 게임 AI (Game AI) · 에이전트 AI (Agent AI)
- 저자: Kaichen He, Zihao Wang, Muyao Li, Anji Liu, Yitao Liang.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, regular paper, pp. 724–734. CVF Open Access proceedings 페이지와 PDF의 서지정보로 게재를 확인했다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/He_Training_One_Model_to_Master_Cross-Level_Agentic_Actions_via_Reinforcement_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/He_Training_One_Model_to_Master_Cross-Level_Agentic_Actions_via_Reinforcement_CVPR_2026_paper.pdf) · [공식 코드·모델 링크](https://github.com/CraftJarvis/OpenHA)
- 원문: [저장소 PDF](../../papers/2026-he-crossha-agentic-actions.pdf)

#### 핵심 요약

`CrossHA`는 고수준 script부터 저수준 primitive control까지의 heterogeneous action space를 하나의 policy가 선택하도록 학습하는 `Minecraft` agent다. 각 시점의 목적은 task reward에서 action cost를 뺀 기대합을 최대화하는 것으로 정의하며, action-space 선택과 action content를 함께 결정한다 (§3, Eq. 1, PDF p. 3).

학습은 (1) balanced mixed-action dataset의 cold-start SFT, (2) 한 단계의 올바른 raw action을 보상으로 쓰는 `Single-Turn RL (STRL)`, (3) episode success와 생성 길이 패널티를 쓰는 `Multi-Turn RL (MTRL)`의 세 단계다 (§3.1–3.3, Eqs. 2–6, PDF pp. 3–5). 평가는 first-person RGB 입력을 쓰는 `Minecraft 1.16.5`의 `OpenHA` benchmark(800개 초과 task)에서 Mine Blocks, Craft Items, Kill Entities의 `Finished Tasks (FT)`와 `Average Success Rate (ASR)`로 한다 (§4.1, PDF p. 5).

OOD 평가에서 `CrossHA`의 ASR은 Mine Blocks 40.0%, Kill Entities 28.4%, Craft Items 78.8%, 전체 49.1%로 표에 제시된다. STRL을 제거하면 Craft Items/전체가 58.0%/39.7%다 (Table 2, §4.4, PDF pp. 7–8).

#### 중요한 이유

[추론] agent의 tool/interface 선택을 hand-coded routing이 아니라 학습되는 policy variable로 취급한다는 점이 핵심이다. 특히 action-space를 고정한 RL baseline은 특정 ID task에서 높아도 OOD에서 크게 떨어지는 사례가 표에 보이며, `CrossHA`는 task마다 필요한 제어 단위를 바꾸려 한다 (Table 2, §4.4, PDF pp. 7–8). 이는 게임 agent의 결과이며, 범용 tool-use로의 일반화는 아직 확인되지 않았다.

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| heterogeneous action space를 하나의 policy가 선택하고, reward와 action cost를 함께 최적화한다. | §3, Eq. 1, PDF p. 3 |
| SFT→STRL→MTRL의 세 단계가 action syntax 학습, one-step 선택, long-horizon optimization을 각각 담당한다. | §3.1–3.3, Fig. 2, Eqs. 2–6, PDF pp. 3–5 |
| 800개 초과 `OpenHA` task에서 FT와 ASR로 평가한다. | §4.1, PDF p. 5 |
| full model이 OOD Craft Items 78.8%, All Tasks 49.1%를 보고한다. | Table 2, §4.4, PDF pp. 7–8 |

#### 한계

저자들은 이후 multi-turn RL의 효율 개선을 future work로 든다 (§5, PDF p. 8). [내 의견] 모든 평가는 `Minecraft 1.16.5`의 first-person RGB·이산 인간형 interface이며 (§4.1, PDF p. 5), 실제 API·GUI·로봇 tool을 섞은 환경에서 dynamic switching이 안전성과 비용을 함께 개선하는지는 원문 결과만으로 알 수 없다 [확인 필요]. OOD 전체 ASR의 표준편차도 46.6으로 제시되어 결과 변동성은 작지 않다 (Table 2, PDF p. 7).

### 3. EVA: Efficient Reinforcement Learning for End-to-End Video Agent

- 카테고리: 에이전트 AI (Agent AI) · 컴퓨터 비전 (Computer Vision)
- 저자: Yaolun Zhang, Ruohui Wang, Jiahao Wang, Yepeng Tang, Xuanyu Zheng, Haonan Duan, Hao Lu, Hanming Deng, Lewei Lu.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, regular paper, pp. 12289–12299. CVF Open Access proceedings 페이지와 PDF의 서지정보로 게재를 확인했다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Zhang_EVA_Efficient_Reinforcement_Learning_for_End-to-End_Video_Agent_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Zhang_EVA_Efficient_Reinforcement_Learning_for_End-to-End_Video_Agent_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../papers/2026-zhang-eva-efficient-reinforcement-learning-video-agent.pdf)

#### 핵심 요약

`EVA`는 긴 video 질의에 대해 전체 frame을 먼저 보는 대신, summary–plan–action–reflection loop로 무엇을·언제·어떻게 볼지 정한 뒤 시각 evidence를 요청하는 end-to-end video agent다 (Abstract, §3, PDF pp. 1, 3–5). `Qwen2.5-VL-7B-Instruct`를 base model로 하며, cold-start SFT, `Kahneman–Tversky Optimization (KTO)`, `Group Relative Policy Optimization (GRPO)`의 세 단계로 학습한다 (§3, §4.1, PDF pp. 3–6).

저자들은 `LSDBench`, `LongVideoBench`, `MLVU`, `VideoMME`, `LVBench`, `Video-Holmes`에서 accuracy를 평가한다 (§4.1, PDF p. 6). `EVA-GRPO`는 Table 2에서 LongVideoBench 55.0, MLVU 68.3, VideoMME-Long/Overall 48.4/60.2, LVBench 43.3을 기록한다 (Table 2, PDF p. 7). `LSDBench` 표에서는 `EVA`가 10.3k visual token으로 51.0 accuracy를 기록하며, 비교 표의 `Gemini-2.0-Flash`는 696.6k token과 56.2 accuracy로 제시된다 (Table 1, PDF p. 6).

#### 중요한 이유

[추론] long-video 성능 경쟁을 더 많은 frame 처리만의 문제로 보지 않고, observation budget을 계획하는 agent policy의 문제로 옮긴다. 논문 표의 token–accuracy 비교는 dense sampling 대신 query-driven perception을 검토할 실증 동기를 준다 (Table 1, §4.2, PDF p. 6). 다만 서로 다른 모델의 token 추정 방식과 benchmark 조건이 있는 비교이므로, 이를 모든 video workload에서의 비용 우위로 일반화할 수는 없다.

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| 계획 후 perception을 수행하는 iterative video-agent loop를 제안한다. | Abstract, §3, Fig. 1–2, PDF pp. 1, 3–5 |
| SFT, KTO, GRPO를 순차 적용하고 GRPO에는 answer correctness·ROUGE·format reward를 사용한다. | §3.1–3.3, Eqs. 3–5, PDF pp. 3–6 |
| 여섯 video benchmark에서 accuracy를 사용해 평가한다. | §4.1, PDF p. 6 |
| `EVA-GRPO`의 long-video benchmark 점수가 Table 2에 제시된다. | Table 2, §4.2, PDF p. 7 |

#### 한계

저자들은 current loop가 predefined tool interface에 의존하고 unseen 또는 noisy query distribution에서 어려울 수 있다고 명시한다 (§5, PDF p. 8). 또한 Table 2의 EVA frame 수에는 650 visual token/frame 가정을 통한 추정값이 포함되며 실제 frame 수는 adaptive resolution에 따라 달라진다 (Table 2 caption, PDF p. 7). 따라서 표의 frame·token 효율을 다른 implementation의 실제 latency나 비용으로 환산하려면 별도 측정이 필요하다 [확인 필요].

#### 중요한 이유

[추론] 이는 모델 출시 뒤의 평가가 아니라 training process와 safety commitment를 외부 평가자가 지속적으로 점검하는 governance proposal을 공개적으로 제기한 사례다. 다만 제안에 대한 타사 수용, 법제화, 위험 감소 효과는 아직 확인되지 않았다 [확인 필요] (Amodei 원문; AP).
