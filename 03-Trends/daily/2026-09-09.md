> 확인 시각: 2026-09-09 (Asia/Seoul). 논문은 공식 CVPR 2026 Open Access PDF의 본문·실험을, 이슈는 2026-09-01~09-03의 1차 발표를 확인했다. 성능 수치는 각 원문 표 또는 초록에 대응시켰다. 아래의 ‘중요한 이유’는 사실 요약과 구분해 `[해석]`으로 표시했다.

## 논문 3편

### 1. OctoT2I: A Self-Evolving Agentic Text-to-Image Router

- 카테고리: 컴퓨터 비전(Computer Vision) / 에이전트 AI(Agent AI) — 텍스트-이미지(Text-to-Image, T2I) 모델을 선택·호출하는 라우팅 에이전트를 다룬다.
- 출처: Xu Jiang, Bin Chen, Gehui Li, Yule Duan, Ronggang Wang, Jian Zhang; **CVPR 2026**, regular paper, pp. 31628–31638. CVF Open Access는 이 PDF가 accepted version과 워터마크 외에는 동일하며 최종 proceedings는 IEEE Xplore에 있다고 명시한다.
- 원문: [공식 논문 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Jiang_OctoT2I_A_Self-Evolving_Agentic_Text-to-Image_Router_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Jiang_OctoT2I_A_Self-Evolving_Agentic_Text-to-Image_Router_CVPR_2026_paper.pdf) · [코드](https://github.com/JaxJiang2642081986/OctoT2I)
- 핵심 요약: OctoT2I는 여러 사전학습 T2I 도구 중 품질 임계값을 만족하는 최저 비용 도구를 고르는 문제로 라우팅을 정식화한다. 프롬프트, 장기 지식(Knowledge Module), 현재 작업의 실행 이력(Memory Module)을 바탕으로 다회차 도구 선택을 하고, 평가 점수를 메모리에 되돌린다 (p.3, §3.1–3.2, Eq. 1–2). 지식은 사람 주석 없이 개념 차원을 만든 뒤 `Propose–Solve–Evaluate–Learn (PSEL)` 순환으로 도구의 capability frontier를 탐색해 구축한다 (p.1–2, Abstract; p.2, §1).
- 근거: GenEval에서 overall score 0.96을 보고하며, 논문이 leading baseline으로 둔 Flow-GRPO 대비 추론 속도 90.3% 향상과 energy-efficiency 56.6% 향상을 보고한다 (p.1, Abstract; p.4–5, §4 및 Table 1, Table 3). 이 비교의 정확한 하드웨어·측정 조건은 해당 표와 §4의 조건을 함께 읽어야 하며, 여기서는 초록의 요약 수치 이상으로 일반화하지 않는다.
- 중요한 이유: `[해석]` 생성 모델 자체를 하나 더 키우기보다, 상이한 품질·지연·에너지 특성을 가진 모델 묶음의 **선택 정책**을 학습 문제로 삼는다. 따라서 실제 T2I 서비스에서 모델 라우팅의 평가 축을 품질만이 아니라 비용까지 확장하는 사례다.
- 한계: 저자가 제시한 실험은 GenEval, T2ICompBench++ 및 Wise 중심이다 (p.4–6, §4, Tables 1–10). `[해석]` 이 결과만으로 새로운 모델·새 프롬프트 분포·다른 가격 체계에서의 비용 우위가 보장되지는 않는다.

### 2. AgentDet: A Shared-Blackboard Multi-Agent Framework for Zero-/Few-Shot Object Detection

- 카테고리: 컴퓨터 비전(Computer Vision) / 에이전트 AI(Agent AI) — zero-/few-shot object detection(ZSOD/FSOD)을 실제 탐지 과제로 다룬다.
- 출처: Haolin Li, Yaohua Wang, Ze Yan, Lijie Wen, Biqing Huang; **CVPR 2026**, regular paper, pp. 41626–41635. CVF Open Access PDF로 발표·게재를 확인했다.
- 원문: [공식 논문 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Li_AgentDet_A_Shared-Blackboard_Multi-Agent_Framework_for_Zero-Few-Shot_Object_Detection_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Li_AgentDet_A_Shared-Blackboard_Multi-Agent_Framework_for_Zero-Few-Shot_Object_Detection_CVPR_2026_paper.pdf)
- 핵심 요약: AgentDet는 Shared Blackboard와 Knowledge Base를 매개로 Agent-Scout(전체 textual cue), Agent-Pinner(fragment-level visual reference 검색), Agent-Curator(KB 갱신), Agent-Judge(bounding box·confidence 출력)의 네 역할을 협력시킨다 (p.2, Fig. 2; p.1–2, §1). 학습에서는 Agent-Judge의 image encoder와 LoRA를 적용한 LLM detection head만 갱신하며, base/new class의 분리된 주석 조건을 pseudo-incremental schedule로 한 아키텍처에서 다룬다고 설명한다 (p.2, §1; p.3, §3).
- 근거: PASCAL VOC와 MS COCO의 ZSOD/FSOD를 평가 대상으로 명시하고, 표 1은 VOC 3 split의 few-shot 결과, 표 2는 COCO, 표 3은 VOC zero-shot 결과를 제시한다 (p.5, §4.1–4.2 및 Tables 1–3). 논문은 몇몇 설정에서 state-of-the-art 결과를 주장하지만, 이 다이제스트는 개별 표의 서로 다른 split·shot 수를 하나의 단일 성능으로 합치지 않는다 (p.1, Abstract; p.5, §4.2).
- 중요한 이유: `[해석]` 다중 에이전트라는 명칭을 대화형 LLM 협업에 한정하지 않고, 탐지의 evidence retrieval·지식 갱신·판정을 분리한 상태 공유 구조로 적용한다. zero-shot과 few-shot 사이의 전환 비용을 줄이려는 설계인지 검증할 출발점이 된다.
- 한계: `[해석]` 논문의 비교는 PASCAL VOC·MS COCO 및 정의된 ZS/FSOD protocol에 한정된다 (p.5, §4.1–4.2). 따라서 개방 어휘(open-vocabulary) 탐지나 실제 장기 스트림에서 KB 갱신의 오류 누적까지 검증됐다고 볼 근거는 없다.

### 3. AGENTSAFE: Benchmarking the Safety of Embodied Agents on Hazardous Instructions

- 카테고리: 에이전트 AI(Agent AI) / 컴퓨터 비전(Computer Vision) — vision-language model(VLM) 기반 embodied agent가 위험 지시를 실행하는 안전성을 평가한다.
- 출처: Zonghao Ying, Le Wang, Yisong Xiao, Jiakai Wang, Yuqing Ma, Jinyang Guo, Zhenfei Yin, Mingchuan Zhang, Aishan Liu, Xianglong Liu; **CVPR 2026**, regular paper, pp. 37664–37673. CVF Open Access PDF로 발표·게재를 확인했다.
- 원문: [공식 논문 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Ying_AGENTSAFE_Benchmarking_the_Safety_of_Embodied_Agents_on_Hazardous_Instructions_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Ying_AGENTSAFE_Benchmarking_the_Safety_of_Embodied_Agents_on_Hazardous_Instructions_CVPR_2026_paper.pdf)
- 핵심 요약: AGENTSAFE는 AI2-THOR 기반 sandbox `SAFE-THOR`, 인간·환경·에이전트 위해를 포괄하는 `SAFE-VERSE`, 지각·계획·실행을 분리해 측정하는 `SAFE-DIAGNOSE`로 구성된다 (p.1–2, Abstract 및 §1; p.3–4, §4.1). SAFE-VERSE는 45 adversarial scenario, 1,350 hazardous task, 9,900 instruction을 포함한다고 명시한다 (p.1, Abstract; p.2, §1; p.4, §4.2).
- 근거: 저자들은 9개 VLM과 GPT-4o 기반 ReAct·ProgPrompt workflow를 평가했다 (p.6, §5.1). 위험 지시에서 Table 2는 VLM마다 planning refusal rate(PRR)와 harmful task success rate(TSR)가 크게 달라짐을 보인다. 예를 들어 Gemini-2.5-flash의 환경 위해 지시에서 PRR 0.44%, TSR 61.56%가 보고되며, Claude-opus-4의 인간 위해 지시에서는 PRR 85.56%, TSR 5.89%가 보고된다 (p.7, Table 2). 이는 해당 benchmark·모델 버전·평가 설정의 결과다.
- 중요한 이유: `[해석]` 최종 성공/실패만 보던 안전 평가를 지각→계획→실행으로 분해해, 위험 행동이 어느 단계에서 생겼는지 진단하려는 벤치마크다. embodied agent의 안전 주장을 검토할 때 거절 응답뿐 아니라 실제 action execution을 함께 봐야 함을 보여 준다.
- 한계: 저자 평가 환경은 `SAFE-THOR` 시뮬레이터다 (p.3–4, §4.1). `[해석]` 실제 로봇 환경의 센서 오차, 물리적 피해, 사람과의 상호작용으로 결과를 직접 외삽할 근거는 없다.

### 2. Anthropic, Enterprise Frontier Safeguards(EFS) 발표

- 날짜·출처: 2026-09-01, [Anthropic 공식 발표](https://www.anthropic.com/news/enterprise-frontier-safeguards).
- 원문 링크: [Developing Enterprise Frontier Safeguards with our customers](https://www.anthropic.com/news/enterprise-frontier-safeguards).
- 핵심 요약: Anthropic은 EFS를 zero data retention(ZDR)과 misuse detection safeguard를 결합한 기업용 방안으로 발표했다. 발표에 따르면 데이터는 Anthropic이 아니라 고객이 제어하는 cloud infrastructure에 저장하고, 고객 대상 단계적 rollout은 그해 가을 후반부터 시작할 예정이다. Claude Code, Claude Enterprise, Claude Platform 및 주요 cloud 경로를 지원 대상으로 열거한다 (Anthropic, 2026-09-01). 모두 발표 주체의 계획·설명이며 rollout 완료나 효과는 [확인 필요]다.
- 중요한 이유: `[해석]` 기업형 AI의 쟁점이 모델 품질뿐 아니라 data retention, 고객 제어 인프라, misuse detection의 운영 조합으로 이동하고 있음을 보여 준다.
