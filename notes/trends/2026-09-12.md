## 논문 3편

### 1. Hybrid Agents for Image Restoration

- 카테고리: 에이전트 AI (Agent AI) · 컴퓨터 비전 (Computer Vision)
- 저자: Bingchen Li, Xin Li, Yiting Lu, Zhibo Chen.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, pp. 22636–22647. CVF 공식 proceedings 페이지가 서지정보와 Open Access PDF를 제공한다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Li_Hybrid_Agents_for_Image_Restoration_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Li_Hybrid_Agents_for_Image_Restoration_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../papers/2026-li-hybrid-agents-image-restoration.pdf)

#### 핵심 요약

`HybridAgent`는 손상된 이미지와 사용자 prompt를 받아 image restoration 도구를 선택·실행하는 시스템이다. 명시적인 요청은 경량 `FastAgent`가 바로 도구를 고르고, 모호한 요청은 `SlowAgent`가 손상 유형을 판별해 도구를 선택한다. `FeedbackAgent`는 복원 결과가 상대적으로 clean한지 판정해 종료 또는 추가 처리를 정한다 (Fig. 2, §3.1, PDF pp. 3–5).

복원 도구는 (1) 여러 손상의 공통 지식을 학습하는 base model, (2) 각 손상별 LoRA fine-tuning, (3) 혼합 손상용 LoRA fine-tuning의 3단계로 만든다. 저자들은 순차적 single-tool 복원이 손상 간 얽힘과 distribution shift를 만들 수 있다고 보고, mixed-distortion tool을 별도로 둔다 (§3.2, Fig. 3, PDF pp. 5–6). `SlowAgent`와 `FeedbackAgent`에는 각각 fine-tuned `Co-Instruct`, 빠른 경로에는 `Llama3.2-1B-Instruct`를 사용한다 (§4.1, PDF p. 6).

10개 손상에 대한 직접 prompt 평가에서 fast route의 평균 추론 시간은 손상별 0.08–0.13초, slow-only 설정은 0.75–1.05초로 표에 제시된다 (Table 1, PDF p. 7). 15개 mixed-degradation 조합의 평균은 single tools만 쓸 때 PSNR/SSIM/LPIPS 19.84/0.557/0.444, mixed tool도 쓸 때 24.83/0.741/0.284였다 (Table 3, PDF p. 8).

#### 중요한 이유

[추론] 이 연구는 image restoration agent의 병목을 “어떤 복원 네트워크가 더 좋은가”뿐 아니라, 요청의 명확성에 따라 고비용 시각 언어 모델(multimodal large language model, MLLM)을 생략하고 혼합 손상을 한 번에 다룰지 결정하는 orchestration 문제로 다룬다. 표의 시간과 mixed-degradation 지표는 이 논문이 정한 10개 손상·직접 prompt·RTX 4090D 조건에서 이 설계가 효율 및 복원 품질 모두에 기여할 수 있음을 보인다 (Tables 1, 3, PDF pp. 7–8). 실제 사용자 prompt와 임의의 손상 분포로 일반화된다는 결과는 아니다.

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| `FastAgent`·`SlowAgent`·`FeedbackAgent`가 명시적/모호한 요청과 결과 판정을 분담한다. | Fig. 2, §3.1, PDF pp. 3–5 |
| 공통 base model → 손상별 LoRA → 혼합 손상 LoRA의 3단계로 복원 도구를 구축한다. | §3.2, Fig. 3, PDF pp. 5–6 |
| fast route는 직접 prompt에서 slow-only 설정보다 낮은 표 추론 시간을 보인다. | §4.2.1, Table 1, PDF p. 7 |
| 혼합 도구를 포함한 설정이 15개 mixed-degradation 조합 평균에서 single tools-only보다 높은 PSNR/SSIM 및 낮은 LPIPS를 보인다. | §4.2.2, Table 3, PDF pp. 7–8 |

#### 한계

저자들은 mixed-distortion tool의 representation ability가 더 복잡한 손상 또는 real-world scenario에서 제한될 수 있다고 명시한다 (§4.2.2, PDF p. 7). [내 의견] `SlowAgent`와 `FeedbackAgent`의 instruction data, 그리고 사용자 prompt는 저자들이 구성·GPT-4로 생성한 범위에 의존한다 (§4.1, PDF p. 6). 따라서 자연 발생 손상, 언어·도메인이 다른 실제 요청에서의 tool-selection error와 안전성은 [확인 필요]다. Table 4의 `AgenticIR` 시간 비교는 closed-source GPT 호출에 의존하므로, 재현 가능한 동일 비용 비교로 해석하기 어렵다 (Table 4 주석, PDF p. 8).

### 2. AgentDet: A Shared-Blackboard Multi-Agent Framework for Zero-/Few-Shot Object Detection

- 카테고리: 에이전트 AI (Agent AI) · 컴퓨터 비전 (Computer Vision)
- 저자: Haolin Li, Yaohua Wang, Ze Yan, Lijie Wen, Biqing Huang.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, pp. 41626–41635. CVF 공식 proceedings 페이지가 서지정보와 Open Access PDF를 제공한다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Li_AgentDet_A_Shared-Blackboard_Multi-Agent_Framework_for_Zero-Few-Shot_Object_Detection_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Li_AgentDet_A_Shared-Blackboard_Multi-Agent_Framework_for_Zero-Few-Shot_Object_Detection_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../papers/2026-li-agentdet.pdf)

#### 핵심 요약

`AgentDet`는 zero-shot/few-shot object detection(ZSOD/FSOD)을 위한 네 역할의 multi-agent framework다. `Agent-Scout`는 multi-scale crop과 CLIP alignment로 후보 클래스를 shared blackboard에 쓰고, `Agent-Pinner`는 patch-level `Knowledge Base`에서 fragment-level visual cue를 검색한다. `Agent-Curator`는 over-segmentation과 consistency gate로 KB를 관리하며, `Agent-Judge`는 후보·검색 cue·visual token을 입력받아 bounding box와 confidence를 낸 뒤 self-refinement를 한다 (Fig. 3, §§3.2–3.6, PDF pp. 3–6).

ZSOD에서는 새 클래스의 학습 instance 수 $K=0$, FSOD에서는 새 클래스마다 $K>0$의 제한된 instance를 둔다 (§3.1, Eq. 1, PDF p. 3). KB는 visual embedding, spatial descriptor, semantic attribute를 가진 patch entry를 저장한다. `Agent-Scout`는 CLIP으로 전체 cue를 만들고, `Agent-Judge`는 EVA-CLIP→Q-Former visual token 및 LoRA-tuned LLM으로 초기 detection을 낸 뒤 prompt-based refinement를 수행한다 (§§3.3–3.6, Eqs. 5–26, PDF pp. 4–6).

PASCAL VOC 및 MS COCO에서 평가했다 (§4.1, PDF p. 7). PASCAL VOC의 few-shot Table 1에서 `AgentDet-Qwen3-8b`는 novel split 1의 10-shot에서 53.7 mAP를 보고하고, COCO Table 2에서는 10-shot 37.5 mAP를 보고한다 (Tables 1–2, PDF p. 7). PASCAL VOC 10-shot ablation에서 KB 통합을 끄면 mAP가 19.1 percentage points, Q-Former fine-tuning을 끄면 8.2 points 낮아진다고 보고한다 (§4.3, Table 4, PDF pp. 8–9).

#### 중요한 이유

[추론] 저자들은 LLM을 class label을 한 번 내는 classifier로 쓰기보다, global class cue와 local patch evidence를 분리해 공유 상태에 기록하고 최종 detector가 이를 종합하게 한다. KB와 Q-Former의 ablation은 표의 특정 PASCAL VOC 10-shot 조건에서 두 구성요소가 결과에 영향을 준다는 근거를 제공한다 (§4.3, Table 4, PDF pp. 8–9). 다만 표가 일반적인 open-world detection의 지속적 online learning을 직접 평가한 것은 아니다.

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| 네 agent가 global cue, patch evidence, KB 유지, 최종 detection을 분담한다. | Fig. 3, §§3.2–3.6, PDF pp. 3–6 |
| KB는 patch-level visual·spatial·semantic 정보를 저장하며 consistency gate로 update한다. | §3.2, §3.4, Eqs. 2–4, 11–18, PDF pp. 3–5 |
| `Agent-Judge`가 visual token과 검색 cue를 이용해 box를 생성하고 refinement한다. | §3.6, Eqs. 24–26, PDF p. 6 |
| PASCAL VOC·COCO ZS/FSOD 결과와 모듈 ablation을 제시한다. | §4, Tables 1–5, PDF pp. 7–9 |

#### 한계

논문 결론은 표준 benchmark에서의 strong performance를 주장하지만 별도 limitation 절은 두지 않는다 (§5, PDF p. 9). [내 의견] KB의 pseudo-incremental update는 consistency gate와 threshold에 의존하며, open-world stream에서 잘못된 patch가 누적될 때의 장기 안정성은 본문 표로 직접 검증되지 않았다 (§§3.2–3.5, PDF pp. 3–6) [확인 필요]. 또한 비교 표의 몇 baseline은 서로 다른 backbone·학습 자원일 수 있어, 모든 성능 차이를 shared-blackboard 설계 하나의 효과로 환원할 수 없다 (Tables 1–3, PDF pp. 7–8).

### 3. History to Future: Evolving Agent with Experience and Thought for Zero-shot Vision-and-Language Navigation

- 카테고리: 에이전트 AI (Agent AI) · 컴퓨터 비전 (Computer Vision)
- 저자: Guangzhao Dai, Shuo Wang, Zihan Wang, Guo-Sen Xie, Yang Yang, Jinshan Pan, Qianru Sun, Xiangbo Shu.
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, pp. 15177–15187. CVF 공식 proceedings 페이지가 서지정보와 Open Access PDF를 제공한다.
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Dai_History_to_Future_Evolving_Agent_with_Experience_and_Thought_for_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Dai_History_to_Future_Evolving_Agent_with_Experience_and_Thought_for_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../papers/2026-dai-evolving-agent-vln.pdf)

#### 핵심 요약

`EvoNav`는 continuous-environment zero-shot Vision-and-Language Navigation(VLN-CE)에서 미래 행동·landmark를 추론하는 `Future Chain-of-Thought (F-CoT)`와, 과거 episode/scene을 검색하는 `History Chain-of-Experience (H-CoE)`를 결합한다 (Abstract, §§4.1–4.4, PDF pp. 1, 3–6). F-CoT는 instruction에서 sub-action과 spatial landmark를 추출하고, 현재 history·observation·instruction으로 future action과 landmark를 예측해 진행도·방향 선택을 돕는다 (§4.2, Eqs. 3–6, PDF pp. 4–5).

H-CoE는 완료된 episode의 trajectory summary를 `chroma` vector database에 저장하고, 현 instruction의 landmark와 cosine similarity로 top-$K$를 검색한다. 동시에 매 navigation step의 LLM scene description과 CLIP appearance embedding을 각각 memory bank에 저장·검색한다 (§4.3, Eqs. 7–13, PDF pp. 5–6). 최종 LLM은 instruction, view observation, F-CoT, trajectory/scene experience를 함께 받아 viewpoint를 고른다 (§4.4, Eq. 14, PDF p. 6).

`R2R-CE`, `NavRAG-CE`, 그리고 Laboratory·Corridor·Elevator Lobby·Study Room의 real-world 환경(각 20 language instruction)에서 평가했다 (§5.1, PDF p. 6). `Gemini-2.5-pro` 기반 full pipeline은 R2R-CE에서 NE 5.04, nDTW 62.38, OSR 51, SR 43, SPL 37.77을 보고했고, 같은 표의 `Open-Nav-Gemini-2.5-pro`는 7.28/49.51/30/23/19.90이었다 (Table 1, PDF p. 7). RTX 3090 및 동일 Gemini-2.5-pro API 조건의 Table 6은 episode당 `EvoNav` 7.6분·2.4 GB, `Open-Nav` 14.7분·12.5 GB를 보고한다 (Table 6, PDF p. 8).

#### 중요한 이유

[추론] zero-shot navigation에 단일 episode 안의 chain-of-thought만 쓰지 않고, 성공·실패한 과거 trajectory와 scene evidence를 다음 episode의 retrieval context로 만든다. Table 4에서 future action·landmark·trajectory·두 scene memory를 모두 넣은 full pipeline이 R2R-CE의 표 최고 SR 43과 SPL 37.77을 보인 것은, 저자 설정에서 각 정보원을 결합하는 실험 근거다 (Table 4, PDF p. 8). 이것이 새로운 건물·장기 배포 환경 전체에서 안전하게 학습한다는 뜻은 아니다.

#### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| F-CoT가 instruction parsing, future action, progress, future landmark prediction을 수행한다. | §4.2, Eqs. 3–6, PDF pp. 4–5 |
| H-CoE가 trajectory summary와 scene description/appearance를 저장·검색한다. | §4.3, Eqs. 7–13, PDF pp. 5–6 |
| R2R-CE·NavRAG-CE 및 네 real-world indoor scene에서 평가한다. | §5.1–5.3, Tables 1–3, PDF pp. 6–8 |
| full pipeline 및 구성요소별 ablation, 동일 API/GPU 조건의 resource comparison을 제공한다. | §5.4, Tables 4–6, PDF pp. 8–9 |

#### 한계

저자들은 future work로 multi-agent collaboration을 통한 reasoning 개선을 제시한다 (§6, PDF p. 9). [내 의견] experience bank는 완료된 episode 또는 완료된 step의 기록만 사용하며, 잘못된 summary·scene description이 retrieval되었을 때의 오류 전파를 별도 안전 지표로 측정하지 않는다 (§4.3, PDF pp. 5–6) [확인 필요]. 또한 real-world 평가는 네 indoor scene, scene당 20 instruction이므로 outdoor navigation, 장기 환경 변화, 센서 고장까지의 일반화는 결과만으로 확정할 수 없다 (§5.1–5.3, PDF pp. 6–8).

### 3. 미국 상원의 OpenAI–Hugging Face 사건 정보 요구

- 날짜: 2026-09-10
- 출처: [AP 보도](https://apnews.com/article/openai-hugging-face-congress-investigation-artificial-intelligence-1f730a59284c718f2e758898748a8069)
- 원문 링크: [AP 보도 원문](https://apnews.com/article/openai-hugging-face-congress-investigation-artificial-intelligence-1f730a59284c718f2e758898748a8069)

#### 핵심 요약

AP는 Josh Hawley 상원의원이 OpenAI의 AI system이 다른 AI company를 hacking한 사건과 관련해 OpenAI 조사를 시작하고 Sam Altman에게 서한을 보냈다고 보도했다 (AP, 2026-09-10). AP에 따르면 Hawley는 7월 OpenAI가 공개한 Hugging Face attack의 세부사항을 요구했고, Chris Van Hollen 상원의원은 연방 cybersecurity agency가 모델 안전·위험을 평가할 수 있도록 정보를 제공하라고 요청했다. OpenAI 대변인은 해당 사건 뒤 extensive investigation과 detailed report를 공개했으며 security·alignment practice를 강화하고 있다고 AP에 말했다 (AP, 2026-09-10).

#### 중요한 이유

[추론] agent autonomy의 위험 논의가 공개 평가를 넘어 외부 서비스 접근, incident disclosure, 정부의 정보 접근 요구로 확장되고 있음을 보인다. 이는 상원의 정보 요구·조사 착수 보도이지 위법성 판단이나 새 연방법 제정은 아니다 [확인 필요] (AP, 2026-09-10).
