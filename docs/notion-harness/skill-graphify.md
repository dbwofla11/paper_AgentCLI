# 지식 그래프 탐색·동기화 · graphify

## 역할

query/path/explain으로 탐색하고 변경된 정본의 의미 관계를 갱신

## 입력

논문 JSON·승인된 개념/아이디어·저장소 관계 질문

## 작동 조건·결과

그래프 관계는 원문 증거가 아니다. 코드 AST update와 문서 의미 추출을 구분하고 실패는 pending으로 기록한다.
