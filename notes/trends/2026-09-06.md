## 1. A Multi-Agent Perception-Action Alliance for Efficient Long Video Reasoning

- 분류: 에이전트 AI (Agent AI) · 컴퓨터 비전 (Computer Vision)
- 저자: Yichang Xu, Gaowen Liu, Ramana Rao Kompella, Tiansheng Huang, Sihao Hu, Fatih Ilhan, Selim Furkan Tekin, Zachary Yahn, Ling Liu
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, CVPR proceedings 수록 (공식 페이지의 서지정보 및 원문 첫 페이지).
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Xu_A_Multi-Agent_Perception-Action_Alliance_for_Efficient_Long_Video_Reasoning_CVPR_2026_paper.html) · [arXiv 2603.14052](https://arxiv.org/abs/2603.14052) · [공식 코드](https://github.com/git-disl/A4VL)
- 원문: [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Xu_A_Multi-Agent_Perception-Action_Alliance_for_Efficient_Long_Video_Reasoning_CVPR_2026_paper.pdf) · [저장소 PDF](../../papers/2026-xu-a4vl-long-video-reasoning.pdf)

### 핵심 요약

`A4VL`은 긴 동영상 질의응답(VideoQA)을 위해 여러 VLM agent가 지각 탐색(perception exploration)과 행동 탐색(action exploration)을 반복하는 training-free 프레임워크다. 각 agent는 소수의 프레임에서 질의별 단서를 만들고, event-based block과 CLIP 유사도로 관련 구간을 고른 뒤, 답변·근거 생성과 상호 평가를 수행한다. 합의가 안 되면 낮은 점수의 agent를 제거하고 새 단서로 다음 라운드를 시작한다 (Abstract, §2, pp.1–4).

### 중요한 이유

[추론] 긴 영상 전체를 고정밀로 처리하는 대신, 질의에 맞춰 프레임을 탐색하고 여러 모델의 이견을 반복 조정하는 설계는 “더 많은 프레임·더 큰 단일 모델” 중심의 확장과 다른 효율화 경로를 제시한다. 저자 표에서 A4VL은 EgoSchema 82.2%, LongVideoBench 72.2%, MLVU 58.0%를 기록했고, EgoSchema 평균 추론 시간은 37초로 제시됐다 (Table 1, Table 3, p.7). 다만 이 수치는 논문이 선택한 agent pool과 백본 모델 조합에 종속된다 (Table 2, p.7).

### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| 다중 agent의 지각–행동 탐색으로 긴 영상의 관련 프레임을 찾는다. | §2, Eq. (1)–(5), pp.2–4 |
| 다섯 VideoQA benchmark에서 강한 정확도와 낮은 지연시간을 보인다. | Table 1, Table 3, p.7 |
| 세 agent의 multi-round 협업과 pruning이 중요하다. | §3.3, Table 4–7, pp.7–8 |

### 메소드

- 입력은 영상 $V$, 질문 $Q$, 선택지 $O$다. 기본 설정에서 각 agent가 먼저 $N_1=4$개 프레임을 무작위로 보고 perception clue를 만든다 (Eq. (1)–(2), p.3).
- 영상을 최대 $B$개 block으로 나누고 각 clue와 block의 CLIP similarity를 계산한다. 점수에 따라 action 단계에서 사용할 $N_2=16$개 프레임을 배분한다 (Eq. (3)–(4), p.4).
- task별 agent pool은 무라벨 video–question pair에서 답 선택지 일치 빈도를 평균내고 상위 3개 agent를 고르는 방식으로 만든다 (Fig. 3, §2.1, p.3).
- 각 agent는 선택 프레임으로 답변과 근거를 생성한다. full consensus가 되면 종료하고, 그렇지 않으면 self/peer 평가 점수 합이 가장 낮은 agent를 pruning한 뒤 다음 라운드에서 clue를 갱신한다 (Fig. 2, §2.3, pp.3–5).

### 실험 및 한계

NeXT-QA, EgoSchema, LongVideoBench, MLVU, Video-MME를 평가했다. Table 1은 Video-MME를 subtitle 사용/미사용으로 나누어 보고하며 A4VL의 평균은 77.2/82.8이다 (Table 1, p.7). EgoSchema에서 majority consensus는 81.4%, full consensus는 82.2%이고 각각 26초, 37초가 걸렸다 (Table 6, p.8). pruning을 제거하면 EgoSchema 정확도가 80.8% 또는 79.4%로 내려가고 시간이 60초가 된다 (Table 7, p.8).

저자는 audio–text–video 입력, 더 풍부한 task-conditioned similarity, neuro-symbolic 기법을 후속 과제로 남겼다 (§4, p.8). [내 의견] 현재 결과는 영상 중심 benchmark와 특정 VLM pool에 대한 검증이므로, 음성·실시간 스트림·새로운 agent 조합으로의 일반화는 원문에서 입증되지 않았다 [확인 필요].

## 2. OctoT2I: A Self-Evolving Agentic Text-to-Image Router

- 분류: 에이전트 AI (Agent AI) · 컴퓨터 비전 (Computer Vision)
- 저자: Xu Jiang, Bin Chen, Gehui Li, Yule Duan, Ronggang Wang, Jian Zhang
- 학회·연도·발표 확인: *Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR)*, 2026, CVPR proceedings 수록 (공식 페이지의 서지정보 및 원문 첫 페이지).
- 출처: [CVF Open Access 공식 페이지](https://openaccess.thecvf.com/content/CVPR2026/html/Jiang_OctoT2I_A_Self-Evolving_Agentic_Text-to-Image_Router_CVPR_2026_paper.html) · [arXiv 2606.01803](https://arxiv.org/abs/2606.01803) · [공식 코드](https://github.com/JaxJiang2642081986/OctoT2I)
- 원문: [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Jiang_OctoT2I_A_Self-Evolving_Agentic_Text-to-Image_Router_CVPR_2026_paper.pdf) · [저장소 PDF](../../papers/2026-jiang-octot2i-agentic-text-to-image.pdf)

### 핵심 요약

`OctoT2I`는 여러 Text-to-Image (T2I) 모델 중 프롬프트별로 품질 임계값을 만족하면서 비용이 가장 낮은 도구를 고르는 agentic router다. 장기 knowledge와 현재 프롬프트의 memory를 이용해 도구를 선택하고, 생성 이미지를 MLLM verifier로 평가한 뒤 임계값에 도달하지 않으면 다음 라운드에서 다시 선택한다 (Eq. (1)–(7), pp.3–4). knowledge는 사람이 쓴 prior나 사람 라벨 없이 `Propose–Solve–Evaluate–Learn (PSEL)` 루프로 구축된다 (§3.3, pp.5–6).

### 중요한 이유

[추론] T2I의 발전을 단일 최강 모델 선택이 아니라 “프롬프트별 품질–추론비용 라우팅” 문제로 바꾼 점이 중요하다. Table 1에서 GenEval overall은 OctoT2I 0.96, Flow-GRPO 0.93이고, Table 2에서 T2ICompBench++ 평균은 0.6618, Flow-GRPO는 0.6332다 (Tables 1–2, pp.5–6). 그러나 초록의 “Flow-GRPO 대비 90.3% inference speedup, 56.6% energy-efficiency gain”은 Table 3의 GenEval 평균 시간 19.07초→10.02초 및 에너지 2.02→1.29 kWh·PUE와 직접 일치하지 않는다. 표의 원자료만 계산하면 각각 약 47.5%, 약 36.1% 감소이므로, 초록의 향상률은 [확인 필요]다 (Abstract, Table 3, p.6).

### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| quality threshold를 만족하는 최소비용 도구 선택으로 routing을 정식화한다. | Eq. (1), §3.1, p.3 |
| knowledge와 memory를 이용한 multi-round reason–act–reflect routing을 사용한다. | Eq. (2)–(7), Fig. 2, pp.3–4 |
| self-evolution이 도구별 capability frontier를 수집한다. | Eq. (8)–(9), §3.3, pp.5–6 |
| GenEval과 T2ICompBench++에서 baseline보다 높은 표 점수를 기록한다. | Tables 1–2, pp.5–6 |

### 메소드

- 도구 집합은 `Flow-GRPO`, `SDXL-Turbo`, `SD-Turbo`, `SANA1.5`, `SANA-Sprint`다. 각 라운드에서 controller가 프롬프트 $p$, 장기 knowledge $K$, 직전 시도 memory $M_{r-1}$를 보고 도구 $t_r$를 고른다 (Eq. (2)–(5), §4.1, pp.4, 6).
- verifier `q_eval`은 프롬프트–이미지 정합성에 대한 yes/no raw logit을 softmax해 연속 점수 $s_r$를 만들며, $s_r\geq\theta$이면 종료하고 아니면 best-so-far와 실행 기록을 memory에 넣는다 (Eq. (4)–(6), p.4).
- self-evolution은 LLM이 color, position, culture, counting 등 개념 차원 $D$를 만들고, 차원 조합 $\tau$를 단순한 것부터 복잡한 것까지 탐색한다. 각 조합에 대해 프롬프트를 제안하고, 도구를 여러 번 실행하고, Pass@1을 평가하고, 결과를 prompt record와 high-level tool profile로 학습한다 (Eq. (8)–(9), §3.3, pp.5–6).
- 구현 기본값은 quality threshold $\theta=0.8$, 최대 라운드 $R=4$, 차원 수 $N_D=7$, 조합별 prompt 수 $N_p=10$, prompt당 생성 횟수 $N_{sol}=5$다. controller는 `Qwen2-0.5B`이며 `GPT-4.1` policy distillation을 사용했고, 실험은 NVIDIA RTX 3090 4장으로 수행됐다 (§4.1, p.6).

### 실험 및 한계

GenEval, T2ICompBench++, WISE와 DiffusionDB 기반 30개 사용자 프롬프트 연구를 사용했다 (§4.1, p.6). Table 3에서 OctoT2I는 평균 시간 10.02초, CO2e 559.50g, kWh·PUE 1.29를 기록했고 Flow-GRPO는 각각 19.07초, 878.72g, 2.02다 (Table 3, p.6). self-evolving knowledge는 GPT internal knowledge 0.85, handcrafted prior 0.93, ours 0.96의 GenEval overall을 보였다 (Table 4, p.7). exploration-space pruning은 overall 0.96을 유지하면서 탐색 prompt를 1270개에서 370개, 평균 시간을 6857.4초에서 2328.7초로 줄였다 (Table 6, p.7).

논문은 WISE에서 다른 LLM으로 바꾼 robustness와 새 도구 추가 실험을 제시하지만, 평가 점수는 LLM verifier, controller, 도구 library 구성에 의존한다 (§4.1, §4.4, p.6–8). [내 의견] “human supervision 없음”은 knowledge acquisition 과정에 대한 주장이지 controller distillation과 verifier까지 인간·외부 모델의 영향을 배제한다는 뜻은 아니다. 또한 초록과 Table 3의 효율 향상률 불일치는 재현·비교 시 반드시 확인해야 할 문제다.

## 3. Fact-Augmented Lookahead Planning for LLM Agents

- 분류: 에이전트 AI (Agent AI)
- 저자: Samuel Holt, Max Ruiz Luyten, Thomas Pouplin, Mihaela van der Schaar
- 학회·연도·발표 확인: *Proceedings of the 29th International Conference on Artificial Intelligence and Statistics (AISTATS)*, 2026, PMLR volume 300, pp.3205–3213 (PMLR 공식 서지정보 및 원문 첫 페이지).
- 출처: [PMLR 공식 proceedings 페이지](https://proceedings.mlr.press/v300/holt26a.html) · [공식 PDF](https://raw.githubusercontent.com/mlresearch/v300/main/assets/holt26a/holt26a.pdf) · [OpenReview 원문](https://openreview.net/pdf?id=BCkwhqeRJV)
- 원문: [저장소 PDF](../../papers/2026-holt-fact-augmented-lookahead-planning.pdf)

### 핵심 요약

`LWM-Planner`는 에피소드가 끝날 때 trajectory에서 task-critical atomic fact를 추출하고, 이를 action proposal·latent world model simulation·state-value estimation에 함께 넣는 lookahead agent다. candidate fact는 predictive-consistency filter로 검사하고, 이후 depth-limited recursive search에서 시뮬레이션된 보상과 leaf value를 결합해 다음 행동을 선택한다. 파라미터 업데이트 없이 in-context learning만으로 온라인 적응을 시도한다 (Abstract, §3, pp.1, 4–5).

### 중요한 이유

[추론] 이 논문은 단순히 inference-time search를 늘리는 대신, 상호작용에서 얻은 압축된 symbolic memory를 search와 LLM simulator의 조건으로 사용하는 방향을 검증한다. Table 1에서 LWM-Planner는 TextFrozenLake 31.80±20.39, CrafterMini 150.30±44.94, ALFWorld-A/B/C 21.33±9.53/22.89±12.11/19.50±8.37의 cumulative return을 기록해 표의 비교군 중 가장 높게 제시됐다 (Table 1, p.7). 다만 Table 1 캡션은 10 random seeds라고 쓰는 반면 §5의 평가 설명은 inference cost 때문에 3 seeds라고 쓰므로, 분산 수치의 seed 수는 [확인 필요]다 (Table 1, §5.1, pp.7–8).

### 주장–근거 대응

| 논문의 주장 | 원문 근거 |
|---|---|
| atomic fact가 state aliasing을 줄이고 시뮬레이션을 grounded하게 만든다는 이론적 동기를 제시한다. | §2.1–2.4, Eq. (1)–(6), pp.2–4 |
| fact extraction/compression과 recursive lookahead를 결합한다. | §3, Algorithm 1–3, pp.4–5 및 Appendix D, pp.25–31 |
| TextFrozenLake, CrafterMini, ALFWorld에서 cumulative return을 개선한다. | §5, Tables 1–2, pp.7–8 |
| 사실 학습이 없는 unguided search보다 fact-grounded planning이 유리하다. | §5.1–5.2, Table 10, Appendix J.8, pp.7–8, 54–55 |

### 메소드

- 단기 history와 장기 atomic-fact set을 유지한다. 에피소드 종료 후 LLM fact extractor가 trajectory에서 최소한의 새 fact를 만들고, simulator로 held-out next-step prediction error가 감소하는지 확인한 fact만 남긴다. 이후 선택적 compression으로 중복·과도하게 구체적인 fact를 합친다 (§3, pp.4–5).
- 현재 observation, history, fact set에서 action proposer가 후보 행동을 최대 branching factor만큼 제안한다. simulator는 후보 행동마다 다음 observation, 즉시 reward, 종료 여부를 예측하고, leaf에서는 value estimator가 미래 보상을 추정한다 (§3, Algorithm 2, pp.4–5, 27–29).
- 행동별 값은 $Q(o_t,a_i)=r'-\lambda_{step}+\gamma\hat V(o')$로 계산하고 가장 높은 행동을 실제 환경에서 수행한다. planning 중 LLM 호출은 입력별로 memoize하며 simulator·value estimator·fact processing은 temperature 0으로 둔다 (§3, Appendix D, pp.5, 25–31).
- 본문 실험은 각 agent를 300 environment steps 동안 실행한다. 비교군은 `ReAct`, `Reflexion`, `Tree-of-Thought`, `Retrieval-Augmented Planning`, `ReAct + FEC`, `Random`이며, benchmark agent의 frozen LLM은 `gpt-4o`다 (§5, Appendix G–H, pp.7–8, 42–43).

### 실험 및 한계

환경은 procedurally generated text FrozenLake, `CrafterMini`, `ALFWorld`다. Table 2는 FrozenLake board/state-action space가 커질 때에도 LWM-Planner의 normalized cumulative return을 비교하며, 4×4·6×6·8×8 설정에서 모두 100.00으로 표기했다 (Table 2, p.8). Appendix J.6의 ALFWorld 300-step 비용 표는 LWM-Planner가 평균 약 993 tokens/call, 총 827,931 tokens, step당 58.6초라고 보고한다 (Table 15, p.54).

저자는 성능이 base LLM 능력, prompt sensitivity, text 환경 중심 평가, exploration–exploitation 설계, 다수 LLM call의 비용에 의존한다고 명시한다 (Appendix K.4–K.5, pp.56–57). 이 논문의 이론식은 LWM-Planner의 formal guarantee가 아니라 idealized abstraction과 model error를 설명하기 위한 motivation이며, 저자도 $\epsilon_{sim}$, $\delta_{model}$, $\epsilon_{plan}$을 측정·최적화하지 않는다고 명시한다 (§2, §5, pp.2–4, 7). [내 의견] 따라서 실제 continuous/multimodal 환경에서 atomic fact가 causal하게 유효하다는 결론까지는 뒷받침하지 않는다.
