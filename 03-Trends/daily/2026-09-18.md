## 논문 3편

### 1. VISTA: A Test-Time Self-Improving Video Generation Agent

- 카테고리: 에이전트 AI · 컴퓨터 비전
- 출처: [CVF Open Access](https://openaccess.thecvf.com/content/CVPR2026/html/Long_VISTA_A_Test-Time_Self-Improving_Video_Generation_Agent_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Long_VISTA_A_Test-Time_Self-Improving_Video_Generation_Agent_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../01-Papers/pdfs/computer-vision/2026-long-vista.pdf)

`VISTA`는 텍스트-비디오 생성을 시간 계획, 후보 tournament, visual·audio·contextual critic, reasoning agent의 prompt refinement loop로 개선한다. 저자들은 single/multi-scene 평가에서 pairwise win rate와 human preference의 개선을 보고한다. 재학습보다 test-time agent loop에 초점을 둔 접근이며, 비용·호출 횟수·세부 실험 조건은 원문 정독 시 확인한다.

### 2. AgentDet: A Shared-Blackboard Multi-Agent Framework for Zero-/Few-Shot Object Detection

- 카테고리: 에이전트 AI · 컴퓨터 비전
- 출처: [CVF Open Access](https://openaccess.thecvf.com/content/CVPR2026/html/Li_AgentDet_A_Shared-Blackboard_Multi-Agent_Framework_for_Zero-Few-Shot_Object_Detection_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Li_AgentDet_A_Shared-Blackboard_Multi-Agent_Framework_for_Zero-Few-Shot_Object_Detection_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../01-Papers/pdfs/computer-vision/2026-li-agentdet.pdf)

`AgentDet`은 zero-/few-shot object detection을 pseudo-incremental learning으로 함께 다루기 위해 Scout, Pinner, Curator, Judge agent가 shared blackboard와 knowledge base를 공유하는 구조를 제안한다. 제한된 supervision에서 기존 범주 지식을 잃지 않으려는 역할 분리 접근이며, class split·학습비용·정확한 수치는 원문 정독 시 확인한다.

### 3. AGENTSAFE: Benchmarking the Safety of Embodied Agents on Hazardous Instructions

- 카테고리: 에이전트 AI · 컴퓨터 비전
- 출처: [CVF Open Access](https://openaccess.thecvf.com/content/CVPR2026/html/Ying_AGENTSAFE_Benchmarking_the_Safety_of_Embodied_Agents_on_Hazardous_Instructions_CVPR_2026_paper.html) · [공식 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Ying_AGENTSAFE_Benchmarking_the_Safety_of_Embodied_Agents_on_Hazardous_Instructions_CVPR_2026_paper.pdf)
- 원문: [저장소 PDF](../../01-Papers/pdfs/agent-ai/2026-ying-agentsafe.pdf)

`AGENTSAFE`는 hazardous instruction을 받는 embodied VLM agent를 위한 `SAFE` benchmark를 제안한다. adversarial simulation sandbox, 45개 scenario·1,350개 hazardous task·9,900개 instruction, perception–planning–execution 진단을 포함한다. simulator 결과는 실제 환경 안전 인증과 구분해 해석해야 한다.
