# 비판 검증 온보딩 설정

- mode: required

`mode`는 사고실험 기획을 실행 전 독립 비판 심사에 보내는 기본 정책이다.

1. `required` — 모든 새 기획은 `grill-me → method/repro/novelty 심사 → 사용자 결정`을 거친다.
2. `on-request` — 사용자가 비판 검증을 요청한 기획에만 적용한다.
3. `off` — 비판 검증을 기본 흐름에서 적용하지 않는다.

처음 사고실험을 시작할 때 `mode: unset`이면 runner는 다음을 반드시 묻고 답을 기다린다.

> 새 사고실험에 비판 검증을 기본 적용할까요?
>
> 1. `required` — grill-me와 독립 3심사를 거친 뒤에만 실험으로 진행합니다.
> 2. `on-request` — 필요하다고 요청한 기획만 심사합니다.
> 3. `off` — 기본 심사를 사용하지 않습니다.

선택 후 이 파일의 `mode`를 갱신한다. 사용자가 변경을 요청할 때만 설정을 바꾼다. `required`는 심사자의 자동 승인이나 자율 실행을 뜻하지 않으며, 최종 진행 판단은 항상 사용자에게 있다.

이 개인 브랜치는 모든 새 사고실험에 비판 검증을 요구하도록 `required`를 선택한다. 심사 결과의 상태 정본은 연결될 Notion 페이지 또는 데이터베이스이며, 대상이 정해지기 전에는 `CRITICAL_VALIDATION_REGISTRY.md`에 임시로 기록한다.
