# 논문 PDF 보관 규칙

PDF는 **저장소에 최초 업로드된 날짜**인 `YYYY-MM-DD/` 하위 디렉터리에 보관한다. 여기서 업로드 시점은 외부 다운로드 시각이 아니라 Git에 해당 파일이 최초로 추가된 commit timestamp를 Asia/Seoul 기준으로 삼는다. 논문 발행일·arXiv 제출일은 메타데이터에 기록하며 폴더 날짜로 사용하지 않는다.

파일명은 `{제1저자성}-{짧은슬러그}.pdf` 형식의 소문자 하이픈 표기를 따른다. 리뷰·즐겨찾기·기타 노트에서 PDF를 참조할 때는 이 상대 경로를 사용한다.

현재 PDF 13편은 모두 `2026-09-02/`에 있으며, 같은 날짜 안의 정확한 업로드 배치는 [UPLOAD_LOG.md](2026-09-02/UPLOAD_LOG.md)에 기록한다.
